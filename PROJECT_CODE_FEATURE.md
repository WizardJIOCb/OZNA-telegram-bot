# Добавление шифра проекта в информацию о сотрудниках

**Дата:** 2025-10-21  
**Функция:** Отображение шифра проекта для сотрудников на объекте

## Что изменено

### 1. PersonnelService.php

#### Добавлен метод `getCurrentProjectCode()`

```php
/**
 * Get current project code for user from their last work entry
 * 
 * @param int $userId
 * @return string - Project code or empty string if not found
 */
public function getCurrentProjectCode(int $userId): string
```

**Логика:**
- Получает последние 10 записей пользователя из табеля
- Ищет первую рабочую активность (через `isWorkActivity()`)
- Извлекает шифр проекта из сообщения по паттерну: `Проект <b>PROJECT_CODE</b>:`
- Возвращает пустую строку, если проект не найден

#### Обновлен метод `getOnsiteEmployees()`

Добавлено поле `project_code` в возвращаемый массив:

```php
$result[] = [
    'user_id' => $user['user_id'],
    'fio' => $user['fio'],
    'days' => $days,
    'start_date' => $sessionStart->format('d.m.Y'),
    'project_code' => $projectCode,  // ← НОВОЕ ПОЛЕ
    'icon' => $icon
];
```

### 2. PersonnelHandler.php

#### Обновлен метод `showOnsiteEmployees()`

Теперь отображает шифр проекта в списке сотрудников:

```php
foreach ($employees as $emp) {
    $daysWord = $this->personnelService->getDaysWord($emp['days']);
    $message .= "{$emp['icon']} {$emp['fio']} - {$emp['days']} {$daysWord}\n";
    $message .= "   📅 На объекте с: {$emp['start_date']}\n";
    
    // Добавляем шифр проекта, если доступен
    if (!empty($emp['project_code'])) {
        $message .= "   💼 Проект: {$emp['project_code']}\n";
    }
    
    $message .= "\n";
}
```

## Особенности реализации

1. **Поиск последней работы:** Метод ищет только рабочие активности (через `isWorkActivity()`)
2. **Защита от пустых значений:** Если проект не найден, возвращается пустая строка
3. **Условное отображение:** Шифр показывается только если он найден (не пустой)
4. **Иконка:** Используется 💼 (портфель) для обозначения проекта
