# Обновление формата отчётов - Changelog

## Дата: 25.10.2025

## Что изменилось

### Новый формат CSV отчётов

Формат отчётов был полностью переработан для удобства анализа и работы с данными.

#### Старый формат:
```csv
Дата,ФИО сотрудника,Функциональное направление,Событие
```

#### Новый формат:
```csv
Проект,Дата,Процесс,Вид деятельности,Основная активность,Тип работ,[Тип работ 2],[Тип работ 3],Фамилия,[Пусто],[Пусто]
```

### Преимущества нового формата

1. **Структурированные данные** - информация разбита на логические категории
2. **Легче фильтровать** - можно быстро отфильтровать по типу работ или процессу
3. **Удобнее для сводных таблиц** - в Excel можно легко создать сводные таблицы
4. **Совместимость с исходным примером** - формат соответствует требованиям пользователя

### Логика парсинга

Система автоматически извлекает из сообщений табеля:
- **Проект** - код проекта (например, ОИ743-03, БКНС120)
- **Дата** - дата активности
- **Процесс** - функциональное направление (Шеф-монтаж, Пусконаладка, Мобильная бригада)
- **Вид деятельности** - основной вид работ (Работы по графику, Подписание акта ШМР и т.д.)
- **Основная активность** - детализация активности (Шеф-монтажные работы, Пусконаладочные работы, Проектная деятельность)
- **Тип работ** - дополнительная детализация (оборудование, подтипы работ)

### Примеры парсинга

#### Пример 1: Шеф-монтаж - Подписание акта
**Исходное сообщение:**
```
✅24.10.2025, Проект ОИ743-03: Добавлена запись в табель: 📋 Подписание акта ШМР
```

**Результат парсинга:**
```csv
ОИ743-03,24.10.2025,Шеф-монтаж,Подписание акта ШМР,Шеф-монтажные работы,,,,
```

#### Пример 2: Шеф-монтаж - Работы по графику
**Исходное сообщение:**
```
✅24.10.2025, Проект ОИ696: Добавлена запись в табель: 📅 Работы по графику (Сборка кровли)
```

**Результат парсинга:**
```csv
ОИ696,24.10.2025,Шеф-монтаж,Работы по графику,Шеф-монтажные работы,Сборка кровли,,,
```

#### Пример 3: Пусконаладка - Изменение схемы
**Исходное сообщение:**
```
✅24.10.2025, Проект БКНС120: Добавлена запись в табель: 🔀 Изменение схемы подключения (Электрооборудование, Дополнительные работы)
```

**Результат парсинга:**
```csv
БКНС120,24.10.2025,Пусконаладка,Изменение схемы подключения,Дополнительные работы,Электрооборудование,,,
```

#### Пример 4: Мобильная бригада
**Исходное сообщение:**
```
✅23.10.2025, Проект ОИ846: Добавлена запись в табель: ⚡️Электромонтажные работы (Досборка)
```

**Результат парсинга:**
```csv
ОИ846,23.10.2025,Мобильная бригада,Электромонтажные работы,Досборка,,,,
```

#### Пример 5: Текущая деятельность
**Исходное сообщение:**
```
✅Запись в табель от 01.10.2025: Текущая деятельность (Медицинский осмотр) добавлена
```

**Результат парсинга:**
```csv
,01.10.2025,Пусконаладка,Медицинский осмотр,,,,,
```

## Обратная совместимость

⚠️ **Внимание**: Новый формат НЕ совместим со старым форматом. Если у вас есть инструменты или скрипты, работающие со старым форматом отчётов, их необходимо обновить.

## Тестирование

Создан тестовый скрипт `test_report_parsing.php` для проверки корректности парсинга различных типов сообщений.

### Запуск тестов:
```bash
php test_report_parsing.php
```

## Дальнейшие шаги

После тестирования в production можно добавить:
1. Дополнительные фильтры по типам работ
2. Автоматическую группировку по видам деятельности
3. Статистику по типам активностей
4. Экспорт в другие форматы (Excel, PDF)

## Примечания

- Все изменения применяются ко всем типам отчётов (простой отчёт, отчёт по проекту, фильтрованный отчёт)
- Парсинг работает как для проектных записей, так и для текущей деятельности
- Эмодзи автоматически удаляются из описаний для чистоты данных
- Тестировщики исключаются из всех отчётов (как и ранее)
