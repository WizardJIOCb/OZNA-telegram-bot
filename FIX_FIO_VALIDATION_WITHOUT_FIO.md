# ИСПРАВЛЕНИЕ: Блокировка заявок без реального ФИО

## Дата исправления
2025-10-12

## Описание проблемы
Администраторы получали заявки на доступ от пользователей, у которых не заполнено ФИО. 
Формально условие проверки выполнялось, но фактически ФИО отсутствовало.

## Анализ проблемы

### Причина
В системе используется значение по умолчанию "Без ФИО", которое автоматически присваивается 
при отсутствии ФИО (файл `Custome/DB.php`, строка 28):

```php
if (!isset($ret["fio"])) $ret["fio"] = "Без ФИО";
```

### Старая проверка (некорректная)
```php
if (empty($userFio) || empty($userFunctionalDirection) || $userFunctionalDirection === 'Не указано') {
    // Блокировать запрос
}
```

**Проблема**: `empty("Без ФИО")` возвращает `false`, потому что строка "Без ФИО" не пустая!
Поэтому пользователи с "Без ФИО" могли отправлять заявки.

### Новая проверка (корректная)
```php
if (empty($userFio) || $userFio === 'Без ФИО' || empty($userFunctionalDirection) || $userFunctionalDirection === 'Не указано') {
    // Блокировать запрос
}
```

**Решение**: Добавлена явная проверка на значение "Без ФИО" в дополнение к проверке на пустоту.

## Внесённые изменения

### 1. Файл: `CustomCommands/Handlers/MainMenuHandler.php`

**Изменено:**
```php
// Было:
if (empty($userFio) || empty($userFunctionalDirection) || $userFunctionalDirection === 'Не указано') {
    // ...
    if (empty($userFio)) {
        $text .= "• Указать ФИО\n";
    }
}

// Стало:
if (empty($userFio) || $userFio === 'Без ФИО' || empty($userFunctionalDirection) || $userFunctionalDirection === 'Не указано') {
    // ...
    if (empty($userFio) || $userFio === 'Без ФИО') {
        $text .= "• Указать ФИО\n";
    }
}
```

### 2. Файл: `CustomCommands/TextmenuCommand.php`

**Изменено:**

Изменён способ получения данных пользователя для избежания ошибок:
```php

// Стало:
$userData = $this->adminService->getUserData($userId);
```
