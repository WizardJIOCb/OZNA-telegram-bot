# Исправление дублирования сообщений для мобильной бригады

## Проблема

При отправке отчетов пользователями с функциональным направлением "Мобильная бригада" по проектам, взятым на контроль, сообщения попадали в **3 места** вместо ожидаемых 2:

1. ✅ **Обычная отправка**: В тему "Мобильная бригада" (group_id: `-1002722176147`, thread_id: `2`)
2. ❌ **Контролируемый проект**: В ту же группу `-1002722176147`, но БЕЗ thread_id (попадает в "генеральную тему")
3. ✅ **Дополнительно**: В настроенный для проекта личный чат или другую группу

## Причина

Дублирование происходило когда:
- Настройки контролируемого проекта указывали `group_id = -1002722176147` (та же группа что и для ФН)
- При этом `chat_id` либо не был указан, либо был пустым
- В результате сообщение отправлялось дважды в одну группу с разными параметрами

## Решение

Добавлена **логика предотвращения дублирования** в `TabelEntry.php`:

### 1. Новый метод `getSenderGroupAndThread()`
Определяет параметры группы и темы для функционального направления отправителя:

```php
private function getSenderGroupAndThread(string $functionalDirection): array
{
    switch ($functionalDirection) {
        case 'Мобильная бригада':
            return ['group_id' => '-1002722176147', 'thread_id' => '2'];
        case 'Пусконаладка':
            return ['group_id' => '-1001400593888', 'thread_id' => '338'];
        case 'Шеф-монтаж':
            return ['group_id' => '-1001865074576', 'thread_id' => '14627'];
        default:
            return ['group_id' => '-1002722176147', 'thread_id' => '2'];
    }
}
```

### 2. Новый метод `isDuplicateDestination()`
Проверяет, приведут ли настройки контролируемого проекта к дублированию:

```php
private function isDuplicateDestination(array $projectSettings, array $senderGroupAndThread): bool
{
    // Если group_id не совпадает, то не дубликат
    if (empty($projectSettings['group_id']) || 
        $projectSettings['group_id'] !== $senderGroupAndThread['group_id']) {
        return false;
    }
    
    // Если group_id совпадает, проверяем thread_id
    $projectThreadId = $projectSettings['chat_id'] ?? null;
    
    // Если chat_id не указан или 'personal', то не дубликат
    if (empty($projectThreadId) || $projectThreadId === 'personal') {
        return false;
    }
    
    // Проверяем, совпадает ли thread_id
    return $projectThreadId === $senderGroupAndThread['thread_id'];
}
```

### 3. Обновленная логика отправки
В методе `sendControlledProjectCopies()` добавлена проверка на дублирование:

```php
// Проверяем на дублирование
$isDuplicate = $this->isDuplicateDestination(
    $projectSettings, 
    $senderGroupAndThread
);

if ($isDuplicate) {
    error_log("TabelEntry: Skipping duplicate for {$projectCode} to supervisor {$supervisorUserId} - same destination as functional direction");
    continue;
}
```
