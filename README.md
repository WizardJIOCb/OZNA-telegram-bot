# Telegram Bot для учета рабочего времени

Этот бот предназначен для учета рабочего времени сотрудников на различных проектах.

## Основные функции

- Запись рабочего времени по проектам
- Управление проектами
- Экспорт данных в CSV
- Система уровней доступа

## Структура проекта

```
ozna_bot/
├── CustomCommands/          # Пользовательские команды бота
├── CustomCommands/Services/ # Сервисы для работы с данными
├── CustomCommands/Handlers/ # Обработчики callback-запросов
├── data/                   # Данные приложения (проекты, заявки)
├── Uploads/                # Загруженные файлы
└── ...
```

## Система уровней доступа

Бот поддерживает 5 уровней доступа:

1. **Гость (0)** - Только доступ к профилю
2. **Пользователь (1)** - Доступ ко всем функциям, кроме админки и супервайзера
3. **Супервайзер (2)** - Доступ к отчетам и расширенным функциям
4. **Администратор (3)** - Доступ к админке и возможность подтверждать заявки
5. **Суперадминистратор (4)** - Полный доступ, назначение админов и супервайзеров

### Управление уровнями доступа

Для управления уровнями доступа доступны следующие инструменты:

1. **Веб-интерфейс**: `admin_access_manager.php` - полный веб-интерфейс для управления
2. **Командная строка**: `manage_access_levels.bat` - batch-файл для управления через консоль
3. **Прямое редактирование**: см. `ACCESS_MANAGEMENT_GUIDE.md` для работы с базой данных напрямую
4. **Через базу данных**: суперадмины теперь хранятся в таблице `ozna_data`, поле `is_super_admin` в JSON-данных пользователя

Подробное руководство: [ACCESS_MANAGEMENT_GUIDE.md](ACCESS_MANAGEMENT_GUIDE.md)

## Установка и настройка

1. Установите зависимости через Composer:
   ```
   composer install
   ```

2. Настройте параметры подключения к базе данных в `CustomCommands/Services/DatabaseService.php`

3. Настройте webhook для вашего бота
