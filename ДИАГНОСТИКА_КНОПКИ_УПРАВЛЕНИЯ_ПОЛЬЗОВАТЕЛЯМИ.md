# 🔍 Диагностика проблемы с кнопкой "Управление пользователями"

## Описание проблемы
Кнопка "Управление пользователями" не работает - при нажатии ничего не происходит.

## Созданные инструменты диагностики

### 1. 📊 Простой мониторинг callback'ов
**Файл:** `simple_callback_monitor.php`
**Назначение:** Проверить, доходят ли callback'и до сервера

**Как использовать:**
1. Откройте в браузере: `http://ваш-сервер/simple_callback_monitor.php`
2. Нажмите "Очистить лог"
3. Откройте бота в Telegram
4. Перейдите: Админка → 🔐 Управление уровнями доступа
5. Нажмите "👥 Управление пользователями"
6. Проверьте результат на странице мониторинга

### 2. 🔍 Детальная диагностика
**Файл:** `debug_user_management_button.php`
**Назначение:** Подробный анализ обработки callback'ов

### 3. 👤 Проверка уровня доступа
**Файл:** `check_user_access_level.php`
**Назначение:** Проверить права доступа пользователя

## Возможные причины и решения

### 1. 🚫 Callback не доходит до сервера
**Симптомы:** Лог в `simple_callback_monitor.php` остается пустым

**Возможные причины:**
- Проблемы с webhook'ом Telegram
- Проблемы с интернет-соединением
- Кнопка имеет неправильный callback_data

**Решение:**
- Проверьте webhook: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`
- Убедитесь, что сервер доступен

### 2. ❌ Недостаточные права доступа
**Симптомы:** Callback доходит, но показывается сообщение об ошибке доступа

**Проверка:**
1. Используйте `check_user_access_level.php`
2. Введите User ID пользователя
3. Проверьте его уровень доступа

**Требования:**
- Уровень доступа 2 (Администратор) или выше
- Для управления пользователями нужны права администратора

**Решение:**
- Повысьте уровень доступа пользователя до администратора
- Или используйте аккаунт суперадминистратора

### 3. 🐛 Проблемы в коде обработчика
**Симптомы:** Callback доходит, права есть, но ничего не происходит

**Проверка:**
- Смотрите детальные логи в `debug_user_management_button.php`
- Проверьте логи сервера на наличие PHP ошибок

**Возможные проблемы:**
- Ошибки в AccessLevelHandler
- Проблемы с базой данных
- Ошибки в CallbackHandlerFactory

### 4. 🗄️ Проблемы с базой данных
**Симптомы:** Callback обрабатывается, но данные не загружаются

**Проверка:**
- Убедитесь, что база данных доступна
- Проверьте подключение к БД
- Убедитесь, что таблица `ozna_data` существует

## Пошаговая диагностика

### Шаг 1: Проверка callback'ов
```
1. Откройте simple_callback_monitor.php
2. Очистите лог
3. Нажмите кнопку в боте
4. Проверьте результат
```

**Если лог пустой:** Проблема с webhook'ом или доставкой callback'ов
**Если есть записи:** Переходите к шагу 2

### Шаг 2: Проверка прав доступа
```
1. Откройте check_user_access_level.php
2. Введите User ID пользователя
3. Проверьте уровень доступа
```

**Если уровень < 2:** Повысьте права доступа
**Если уровень >= 2:** Переходите к шагу 3

### Шаг 3: Детальная диагностика
```
1. Откройте debug_user_management_button.php
2. Следуйте инструкциям
3. Анализируйте детальные логи
```

### Шаг 4: Проверка логов сервера
```
1. Проверьте PHP error log
2. Найдите ошибки, связанные с AccessLevelHandler
3. Исправьте найденные проблемы
```

## Техническая информация

### Ожидаемый поток выполнения:
1. Пользователь нажимает кнопку "👥 Управление пользователями"
2. Telegram отправляет callback_data: `acc_lvl_manage_users`
3. CallbackqueryCommand получает callback
4. Callback проходит через early exit фильтр (проверка `acc_lvl_`)
5. CallbackHandlerFactory находит подходящий обработчик (AccessLevelHandler)
6. AccessLevelHandler.canHandle() возвращает true
7. AccessLevelHandler.handle() вызывается с категорией `acc_lvl_manage_users`
8. Проверяется уровень доступа пользователя (должен быть >= 2)
9. Вызывается showUsersWithAccess()
10. Отправляется список пользователей с доступом

### Критические точки:
- **Early exit фильтр:** Должен пропускать `acc_lvl_*` callbacks
- **AccessLevelHandler регистрация:** Должен быть зарегистрирован в CallbackHandlerFactory
- **Права доступа:** Пользователь должен быть администратором (уровень >= 2)
- **База данных:** Должна быть доступна и содержать данные пользователей

## Контакты для поддержки
При возникновении проблем обратитесь к разработчику с результатами диагностики.
