# Исправление подтверждений активностей проектной деятельности ШМР

## Проблема
При нажатии кнопки "Да" в диалоге подтверждения активностей проектной деятельности ШМР система показывала ошибку **"Неизвестная команда табеля"** и не отправляла сформированные отчеты.

## Причина
Система не распознавала команды подтверждения с форматом `category_Табель_ШМ_*_yes` для проектных активностей ШМР. В методе `isActivityExecution()` отсутствовал специальный паттерн для обработки этих команд.

## ✅ Выполненное исправление

### Файл: `CustomCommands/Handlers/TabelHandler.php`

Добавлен специальный паттерн в метод `isActivityExecution()` для распознавания команд подтверждения проектных активностей ШМР:

```php
// Handle supervision project activities with ШМ prefix
if (preg_match('/^category_Табель_(ШМ_УчастиеВЗПИ|ШМ_РазрПрограммы|ШМ_РазрГрафика|ШМ_ОргДопоставки|ШМ_УчастиеВОПИ|ШМ_ИспобязМастера)_yes$/', $category, $matches)) {
    error_log("TabelHandler: isActivityExecution returning true for supervision project activity: {$matches[1]}");
    return true;
}
```

## 🎯 Исправленные команды

Теперь система корректно распознает следующие команды подтверждения:

1. **`category_Табель_ШМ_УчастиеВЗПИ_yes`** - Участие в ЗПИ (ШМР)
2. **`category_Табель_ШМ_РазрПрограммы_yes`** - Разработка программы работ (ШМР)
3. **`category_Табель_ШМ_РазрГрафика_yes`** - Разработка графика работ (ШМР)
4. **`category_Табель_ШМ_ОргДопоставки_yes`** - Организация допоставки (ШМР)
5. **`category_Табель_ШМ_УчастиеВОПИ_yes`** - Участие в ОПИ (ШМР)
6. **`category_Табель_ШМ_ИспобязМастера_yes`** - Исполнение обязанностей мастера (ШМР)
