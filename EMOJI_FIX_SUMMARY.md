# Исправление проблемы с эмодзи в отчётах

## Проблема
После реализации функциональности отображения "Простой" в отчётах, была замечена новая проблема - в отчётах начали появляться эмодзи (в частности, символ паузы ⏸️), которые не должны отображаться в результатах.

## Причина проблемы
1. В сообщениях формата INCIDENT (для "Простой") используется эмодзи паузы: `⏸️ Простой (Шеф-монтаж) (Прочее (Отсутствует готовность ГИ заказчиком))`
2. Существующая функция удаления эмодзи использовала неполный регулярное выражение, которое не охватывало все типы эмодзи
3. Специфическая обработка эмодзи паузы отсутствовала

## Решение
### 1. Улучшена функция удаления эмодзи
В файле `CustomCommands/Handlers/ProjectHandler.php` функция `parseDescription` была обновлена:

**Было:**
```php
// Remove emojis
$desc = preg_replace('/[\x{1F600}-\x{1FFFF}]+/u', '', $desc);
```

**Стало:**
```php
// Remove emojis with comprehensive regex
$desc = preg_replace('/[\x{1F600}-\x{1FFFF}\x{1F300}-\x{1F5FF}\x{1F680}-\x{1F6FF}\x{1F1E0}-\x{1F1FF}\x{2702}-\x{27B0}\x{24C2}-\x{1F251}]+/u', '', $desc);
$desc = trim($desc);

// Special handling for INCIDENT format - remove pause emoji from main
if (strpos($desc, 'Простой') !== false) {
    // Remove pause emoji (both with and without variation selector)
    $desc = preg_replace('/⏸[\x{FE0F}]?/u', '', $desc);
    $desc = preg_replace('/\s+/', ' ', $desc); // Normalize whitespace
    $desc = trim($desc);
}
```

### 2. Что было улучшено:
- **Расширенное регулярное выражение**: Теперь охватывает все основные диапазоны эмодзи
- **Специальная обработка паузы**: Удаляет символ паузы `⏸` с учётом вариационного селектора `️`
- **Нормализация пробелов**: После удаления эмодзи нормализуются пробелы
