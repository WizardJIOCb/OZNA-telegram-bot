# Система управления проектами - Документация

## Обзор
Система управления проектами добавляет кнопку "Проекты" в главное меню бота и предоставляет функционал для работы с личными списками проектов.

## Структура меню

### Главное меню "Проекты"
Доступно для всех зарегистрированных пользователей (уровень доступа 1+):

```
📁 Проекты
├── 📂 Мои проекты
├── 📊 Моя активность (в разработке)
├── 🗂️ Карточка проекта (в разработке)
└── 📋 Отчёт по проекту (в разработке)
```

### Подменю "Мои проекты"
```
📂 Мои проекты
├── 📋 Проекты для отчёта (доступно всем)
└── 🔍 Проекты на контроле (только для супервайзеров+, в разработке)
```

## Уровни доступа

### Уровень 0 (Гость)
- ❌ Кнопка "Проекты" не отображается
- ❌ Нет доступа к функциям проектов

### Уровень 1+ (Пользователь)
- ✅ Кнопка "Проекты" отображается в главном меню
- ✅ Доступ к "Моим проектам"
- ✅ Доступ к "Проектам для отчёта"
- ❌ Нет доступа к "Проектам на контроле"

### Уровень 2+ (Супервайзер)
- ✅ Всё из уровня 1+
- ✅ Доступ к "Проектам на контроле" (в разработке)

### Уровень 3+ (Администратор)
- ✅ Всё из уровня 2+

### Уровень 4 (Суперадминистратор)
- ✅ Всё из уровня 3+

## Функциональность

### Реализованные функции

#### "Проекты для отчёта"
- **Назначение**: Личный список проектов пользователя для формирования отчётов
- **Логика**: Аналогична системе добавления/удаления отчётов в "Админке"
- **Возможности**:
  - ➕ Добавить проект из общего списка системы
  - ➖ Удалить проект из личного списка
  - 📋 Просмотр текущего списка проектов

#### Основное меню проектов
- 📂 Мои проекты - переход к подменю
- 📊 Моя активность - заглушка "в разработке"
- 🗂️ Карточка проекта - заглушка "в разработке"
- 📋 Отчёт по проекту - заглушка "в разработке"

### Функции в разработке

#### "Проекты на контроле"
- **Назначение**: Личный список проектов, копии отчётов по которым направляются в определённые группы и чаты Telegram
- **Планируемый функционал**:
  - Выбор проектов для контроля
  - Настройка ID группы и ID чата для каждого проекта
  - Автоматическая отправка копий отчётов руководителям проектов
- **Доступ**: Только для супервайзеров, администраторов и суперадминистраторов

## Техническая реализация

### Файлы системы
1. **`CustomCommands/Handlers/ProjectHandler.php`** - основной обработчик проектов
2. **`CustomCommands/Services/MessageService.php`** - обновлён для поддержки кнопки "Проекты"
3. **`CustomCommands/TextmenuCommand.php`** - обновлён для обработки reply-кнопки "Проекты"
4. **`CustomCommands/CallbackqueryCommand.php`** - зарегистрирован ProjectHandler

### Структура callback данных
- `category_Проекты` - главное меню проектов
- `category_Проекты_МоиПроекты` - подменю "Мои проекты"
- `category_Проекты_ПроектыДляОтчёта` - управление проектами для отчёта
- `category_Проекты_ПроектыНаКонтроле` - управление проектами на контроле
- `proj_list_add` - добавление проекта для отчёта
- `proj_list_remove` - удаление проекта для отчёта
- `proj_ctrl_*` - callback'и для проектов на контроле (в разработке)

### Хранение данных
Личные списки проектов сохраняются в базе данных в JSON-формате в поле `data`:
```json
{
  "report_projects": ["ОИ834", "БКНС115"],
  "control_projects": {
    "ОИ795": {
      "group_id": "-1001234567890",
      "chat_id": "-987654321"
    }
  }
}
```
