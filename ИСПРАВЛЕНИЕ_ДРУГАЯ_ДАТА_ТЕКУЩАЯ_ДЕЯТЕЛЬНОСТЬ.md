# Исправление: "Другая дата" для Текущей деятельности ✅

## Проблема
После выбора "Другая дата" для Текущей деятельности и ввода даты система показывала список проектов вместо видов деятельности.

## Причина
Было ДВА уровня проблемы:
1. **TabelHandler** терял контекст Текущей деятельности при выборе "Другая дата"
2. **GenericmessageCommand** обрабатывал ввод даты и всегда переходил к выбору проекта

## Решение
Внесены изменения в два файла:

### 1. TabelHandler.php
- **handleDateSelection()**: Сохраняет флаг `is_current_activity` при выборе "Другая дата"
- **handleCustomDateInput()**: Пропускает выбор проекта для Текущей деятельности

### 2. GenericmessageCommand.php  
- **handleDateInput()**: Проверяет флаг `is_current_activity` и передает обработку в TabelHandler

## Результат

### БЫЛО (неправильно):
1. Пользователь: Текущая деятельность → Другая дата → Вводит дату
2. ❌ Система: Показывает список проектов

### СТАЛО (правильно):
1. Пользователь: Текущая деятельность → Другая дата → Вводит дату
2. ✅ Система: Показывает виды деятельности
   - 👨‍⚕️ Медицинский осмотр
   - 📚 Аттестация
   - 🏢 Подготовка ТКП
   - 📊 Общая деятельность

## Инструкция по проверке

1. Откройте бота в Telegram
2. Нажмите кнопку **Табель**
3. Выберите **📊 Текущая деятельность**
4. Выберите **📆 Другая дата**
5. Введите дату (например, `15.10.2025`)

### Ожидаемый результат:
✅ Сообщение: "Табель - Текущая деятельность за 15.10.2025"  
✅ Появляются кнопки видов деятельности (НЕ список проектов)

### Неправильный результат (не должно быть):
❌ Сообщение: "Табель за 15.10.2025, выбор проекта"  
❌ Появляется список проектов
