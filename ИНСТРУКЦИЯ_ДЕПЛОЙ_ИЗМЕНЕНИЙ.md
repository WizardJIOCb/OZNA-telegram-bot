# 🚀 Инструкция по развертыванию изменений на сервере

## Проблема

Мы внесли изменения в локальные файлы:
- ✅ `hook.php` - добавлена принудительная загрузка GenericmessageCommand
- ✅ `CustomCommands/GenericmessageCommand.php` - добавлено логирование
- ✅ `CustomCommands/Handlers/ProjectModerationHandler.php` - исправлена очистка состояний

**НО** бот работает на **удаленном сервере**: `api.ladyzenko.pro/tg/ozna/`

## Что нужно сделать

Изменения нужно **загрузить на сервер**. Есть несколько способов:

### Вариант 1: Через FTP/SFTP

1. Открыть FTP клиент (например, FileZilla, WinSCP)
2. Подключиться к серверу `api.ladyzenko.pro`
3. Перейти в папку `/var/www/api.ladyzenko.pro/tg/ozna/`
4. Загрузить файлы:
   - `hook.php`
   - `CustomCommands/GenericmessageCommand.php`
   - `CustomCommands/Handlers/ProjectModerationHandler.php`

### Вариант 2: Через SSH

```bash
# Подключиться к серверу
ssh user@api.ladyzenko.pro

# Перейти в директорию бота
cd /var/www/api.ladyzenko.pro/tg/ozna/

# Скопировать файлы с локальной машины (с другого терминала)
scp c:\ozna_bot\hook.php user@api.ladyzenko.pro:/var/www/api.ladyzenko.pro/tg/ozna/
scp c:\ozna_bot\CustomCommands\GenericmessageCommand.php user@api.ladyzenko.pro:/var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/
scp c:\ozna_bot\CustomCommands\Handlers\ProjectModerationHandler.php user@api.ladyzenko.pro:/var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/Handlers/
```

### Вариант 3: Через Git (если используется)

```bash
# На локальной машине
cd c:\ozna_bot
git add hook.php CustomCommands/GenericmessageCommand.php CustomCommands/Handlers/ProjectModerationHandler.php
git commit -m "Fix: GenericmessageCommand loading and project add state clearing"
git push

# На сервере
ssh user@api.ladyzenko.pro
cd /var/www/api.ladyzenko.pro/tg/ozna/
git pull
```

### Вариант 4: Редактировать напрямую на сервере

```bash
# Подключиться к серверу
ssh user@api.ladyzenko.pro

# Редактировать файлы напрямую
nano /var/www/api.ladyzenko.pro/tg/ozna/hook.php
nano /var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/GenericmessageCommand.php
nano /var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/Handlers/ProjectModerationHandler.php
```

## Проверка после деплоя

После загрузки изменений попросить пользователя:

1. Нажать: **Проекты** → **Добавить проект**
2. Ввести название: **ТЕСТ4**

Затем проверить логи на сервере:

```bash
# На сервере
tail -f /var/www/api.ladyzenko.pro/tg/ozna/telegram_bot_error.log | grep -E "CUSTOM GenericmessageCommand|project_mod|ТЕСТ"
```

Или локально:
```powershell
Get-Content c:\ozna_bot\telegram_bot_error.log -Wait -Tail 20 | Select-String -Pattern "CUSTOM|project_mod|ТЕСТ"
```
