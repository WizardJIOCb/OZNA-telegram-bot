Управление уровнями доступа

Примечание: Для использования веб-интерфейса управления уровнями доступа необходим установленный PHP.

Введение

Эта система управления уровнями доступа позволяет:

  • Проверять текущие уровни доступа пользователей
  • Одобрять заявки на доступ
  • Добавлять новых администраторов
  • Сбрасывать уровни доступа до уровня Гостя

Уровни доступа

  1. Гость (0) - Только доступ к профилю
  2. Пользователь (1) - Доступ ко всем функциям, кроме админки
  3. Администратор (2) - Доступ к админке и возможность подтверждать заявки
  4. Суперадминистратор (3) - Полный доступ, назначение админов

Использование веб-интерфейса

Запуск веб-сервера

Для использования веб-интерфейса необходимо запустить встроенный в PHP веб-сервер:

cd c:\ozna_bot
php -S localhost:8000

После запуска сервера откройте в браузере адрес: http://localhost:8000/admin_access_manager.php

Функции веб-интерфейса

1. Проверка уровня доступа пользователя

Введите User ID и имя пользователя для проверки текущего уровня доступа.

2. Добавление администратора

Введите User ID, имя пользователя и Chat ID для назначения пользователя администратором.

3. Сброс до уровня Гостя

Введите User ID и имя пользователя для сброса уровня доступа до Гостя.

4. Заявки на доступ

Просмотрите список всех заявок на доступ и одобрите их одним кликом.

5. Информация о пользователях

Просмотрите информацию о ключевых пользователях системы.

Альтернативные способы управления

Использование batch-файла

Запустите файл manage_access_levels.bat для управления уровнями доступа через командную строку.

Прямое редактирование базы данных

См. подробное руководство в файле ACCESS_MANAGEMENT_GUIDE.md.

Важно: Перед выполнением любых операций по изменению уровней доступа рекомендуется создать резервную копию базы данных.

Первичная настройка

  1. Определите пользователей, которые будут первыми администраторами
  2. Используйте веб-интерфейс или batch-файл для назначения этих пользователей администраторами
  3. Проверьте, что назначенные администраторы могут получить доступ к админке
  4. После подтверждения работы системы, рассмотрите возможность сброса остальных пользователей до уровня Гость

Устранение неполадок

  • PHP не найден: Укажите полный путь к PHP.exe при запуске batch-файла
  • Ошибка подключения к базе данных: Проверьте параметры подключения в DatabaseService.php
  • Заявка одобрена, но доступ не предоставлен: Проверьте реализацию approveAccessRequest в AdminService.php
