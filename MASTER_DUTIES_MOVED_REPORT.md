# Отчет о переносе активности "Исполнение обязанностей мастера"

Перенести активность "Исполнение обязанностей мастера" из основного меню отдела ШМР в подменю "Проектная деятельность" отдела ШМР.


### 2. TabelHandler.php

#### Перенос обработчика callback'а:
Обработчик перемещен из раздела основного меню в раздел обработки проектных активностей ШМР:
```php
// Supervision: Master duties (within project activities)
if ($category === 'Табель_ШМ_ИспобязМастера') {
    error_log("TabelHandler: handling supervision master duties activity");
    $projectCode = $conversation->notes['project_code'] ?? 'Unknown';
    $confirmationText = $this->tabelEntry->getConfirmationMessage('ШМ_ИспобязМастера', $projectCode);
    $keyboard = $this->messageService->createConfirmationKeyboard("category_Табель_ШМ_ИспобязМастера_yes");
    return $this->messageService->sendMessage($chatId, $confirmationText, $keyboard);
}
```

### 3. TabelEntry.php
Названия активности остались без изменений:
```php
'ШМ_ИспобязМастера' => 'Исполнение обязанностей мастера (ШМР)'
```
