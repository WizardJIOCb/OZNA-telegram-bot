# Система уровней доступа бота OznaWork

## Общее описание

Реализована 5-уровневая система доступа к функциям бота:

1. **Гость (Guest)** - Уровень 0
2. **Пользователь (User)** - Уровень 1
3. **Супервайзер (Supervisor)** - Уровень 2
4. **Администратор (Admin)** - Уровень 3
5. **Суперадминистратор (Super Admin)** - Уровень 4

## Уровни доступа и их возможности

### Уровень 0: Гость (Guest)
**Права:**
- Просмотр профиля
- Заполнение профиля
- Запрос повышения до Пользователя

### Уровень 1: Пользователь (User)
**Права:**
- Все возможности Гостя
- Использование всех основных функций бота
- Работа с табелем

### Уровень 2: Супервайзер (Supervisor)
**Права:**
- Все возможности Пользователя
- Просмотр отчетов
- Просмотр активности пользователей
- Доступ к расширенным функциям (в разработке)

### Уровень 3: Администратор (Admin)
**Права:**
- Все возможности Супервайзера
- Доступ к админке
- Управление проектами
- Подтверждение заявок от Гостей
- Повышение Гостей до Пользователей

### Уровень 4: Суперадминистратор (Super Admin)
**Права:**
- Все возможности Администратора
- Назначение Администраторов
- Назначение Супервайзеров
- Полный доступ ко всем функциям бота

## Управление уровнями доступа

### Для пользователей:
- Просмотр текущего уровня доступа через профиль
- Запрос повышения уровня через команду `/requestaccess` или кнопку в профиле

### Для администраторов:
- Повышение Гостей до Пользователей через админку
- Повышение Пользователей до Супервайзеров через админку
- Использование команды `/promote <user_id>` для повышения уровня
- Использование команды `/demote <user_id>` для понижения уровня

### Для суперадминистраторов:
- Все возможности администраторов
- Назначение Администраторов
- Назначение Супервайзеров
- Управление всеми уровнями доступа

## Техническая реализация

### Файлы, связанные с системой уровней доступа:
1. `CustomCommands/Services/DatabaseService.php` - Расширена для работы с уровнями доступа
2. `CustomCommands/Services/AdminService.php` - Расширена для управления уровнями доступа
3. `CustomCommands/Handlers/AccessLevelHandler.php` - Обработчик для управления уровнями доступа
4. `CustomCommands/Handlers/SupervisorHandler.php` - Новый обработчик для функций супервайзера
5. `CustomCommands/RequestAccessCommand.php` - Команда для запроса повышения уровня
6. `CustomCommands/PromoteCommand.php` - Команда для повышения уровня пользователя
7. `CustomCommands/DemoteCommand.php` - Команда для понижения уровня пользователя
8. `Custome/DB.php` - Расширена для работы с уровнями доступа

### Константы уровней доступа:
```php
DatabaseService::ACCESS_LEVEL_GUEST = 0
DatabaseService::ACCESS_LEVEL_USER = 1
DatabaseService::ACCESS_LEVEL_SUPERVISOR = 2
DatabaseService::ACCESS_LEVEL_ADMIN = 3
DatabaseService::ACCESS_LEVEL_SUPER_ADMIN = 4
```

### Методы для работы с уровнями доступа:
1. `AdminService::getUserAccessLevel($userId)` - Получить уровень доступа пользователя
2. `AdminService::updateUserAccessLevel($userId, $newLevel)` - Обновить уровень доступа пользователя
3. `AdminService::hasAccessLevel($userId, $requiredLevel)` - Проверить, имеет ли пользователь определенный уровень доступа
4. `AdminService::getAccessLevelName($accessLevel)` - Получить текстовое описание уровня доступа
5. `DatabaseService::isUserSuperAdmin($userId)` - Проверить, является ли пользователь суперадмином
6. `DatabaseService::setSuperAdmin($userId, $isSuperAdmin)` - Назначить/разжаловать суперадмина
7. `DatabaseService::getAllSuperAdmins()` - Получить список всех суперадминов

## Безопасность

1. Пользователи не могут повышать уровень доступа другим пользователям с равным или более высоким уровнем
2. Только Администраторы могут назначать Супервайзеров
3. Только Суперадминистраторы могут назначать Администраторов
4. Все изменения уровней доступа логгируются и уведомляют соответствующих пользователей

## Миграция суперадминов

Ранее список суперадминов хранился в хардкоде в файле `AdminService.php`. 
Теперь суперадмины хранятся в базе данных в таблице `ozna_data` в поле `is_super_admin` JSON-данных пользователя.

Для миграции существующих суперадминов создан скрипт `migrate_super_admins_to_database.php`.

## Тестирование

Для тестирования системы уровней доступа создан скрипт `test_access_levels.php`, который проверяет:
- Получение текущего уровня доступа пользователя
- Проверка статуса суперадмина
- Проверка наличия доступа к определенным уровням
- Получение текстовых описаний уровней доступа

Дополнительно созданы скрипты:
- `test_super_admin_database.php` - для тестирования функциональности суперадминов в базе данных
- `migrate_super_admins_to_database.php` - для миграции существующих суперадминов в базу данных
- `test_supervisor_level.php` - для тестирования функциональности уровня Супервайзер.
