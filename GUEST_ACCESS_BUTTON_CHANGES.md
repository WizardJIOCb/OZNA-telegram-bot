# ИЗМЕНЕНИЯ: Кнопка "Запросить доступ" в главном меню

## Дата изменения
2025-10-12

## Описание проблемы
Пользователи-гости жаловались, что кнопка "Запросить доступ" находится в профиле, 
и возникают сложности с её быстрым получением.

## Реализованные изменения

### 1. Добавлена кнопка "🔐 Запросить доступ" в постоянное меню для гостей
**Файл**: `CustomCommands/Services/MessageService.php`
- Кнопка добавлена в постоянную клавиатуру (Reply Keyboard) внизу экрана
- Кнопка видна ТОЛЬКО для гостей (уровень доступа 0)
- Другие уровни пользователей эту кнопку НЕ видят

**Текущее меню для гостей**:
```
👤 Профиль        ❓ Помощь
🔐 Запросить доступ
```

**Текущее меню для обычных пользователей**:
```
📊 Табель         ❓ Помощь
👤 Профиль        📁 Проекты
⚙️ Админка
```

### 2. Добавлена обработка кнопки "Запросить доступ"
**Файл**: `CustomCommands/TextmenuCommand.php`
- Добавлен обработчик для кнопки "🔐 Запросить доступ"
- Проверяет заполненность профиля перед отправкой запроса
- Если профиль не заполнен - показывает инструкции по заполнению
- Если профиль заполнен - отправляет запрос администраторам

### 3. Удалена кнопка "Запросить доступ" из профиля
**Файл**: `CustomCommands/Handlers/ProfileHandler.php`
- Убрана кнопка "📝 Запросить доступ" из профиля гостя
- Добавлена информационная надпись с указанием, где найти кнопку
- Избежание дублирования функционала

### 4. Добавлен публичный метод для получения данных пользователя
**Файл**: `CustomCommands/Services/AdminService.php`
- Добавлен метод `getUserData()` для доступа к данным пользователя

## Как это работает

### Для гостей (уровень доступа 0):
1. После входа в бота (/start) внизу экрана видна кнопка "🔐 Запросить доступ"
2. При нажатии на кнопку система проверяет профиль:
   - **Профиль не заполнен**: Показывает сообщение с требованием заполнить ФИО и функциональное направление
   - **Профиль заполнен**: Отправляет запрос администраторам с данными пользователя
3. После отправки запроса пользователь получает подтверждение

### Для пользователей с доступом выше гостя:
1. Кнопка "Запросить доступ" НЕ отображается
2. Видны только стандартные кнопки меню

## Проверка изменений

### Автоматический тест
Запустите скрипт проверки:
```bash
php test_guest_access_button.php
```

### Ручная проверка в боте:
1. Войдите в бота как гость (уровень доступа 0)
2. Отправьте команду `/start`
3. Убедитесь, что внизу экрана есть кнопка "🔐 Запросить доступ"
4. Нажмите на кнопку
5. Проверьте корректность обработки:
   - Если профиль не заполнен → показывает предупреждение
   - Если профиль заполнен → отправляет запрос
6. Войдите в профиль и убедитесь, что там НЕТ кнопки "Запросить доступ"
