# 🚨 СРОЧНАЯ ДИАГНОСТИКА - Кнопка не работает

## Проблема
Файлы загружены на сервер, но кнопка "Простой отчёт" не показывает экран выбора даты.

## Шаг 1: Проверить, что PHP-FPM был перезапущен

```bash
sudo systemctl restart php8.3-fpm
```

Затем проверить статус:
```bash
sudo systemctl status php8.3-fpm
```

**Ожидаемый результат**: "Active: active (running)" и время запуска должно быть НЕДАВНИМ (несколько секунд/минут назад).

---

## Шаг 2: Очистить OPcache

```bash
sudo systemctl restart php8.3-fpm
```

Или создать файл на сервере:
```bash
echo "<?php opcache_reset(); echo 'OPcache cleared';" > /var/www/api.ladyzenko.pro/tg/ozna/clear_cache.php
```

Затем открыть в браузере: `https://api.ladyzenko.pro/tg/ozna/clear_cache.php`

---

## Шаг 3: Проверить, что файлы действительно обновились

```bash
ls -lh /var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/Handlers/ProjectHandler.php
```

**Важно**: Проверить дату и время модификации файла. Должна быть СЕГОДНЯШНЯЯ дата.

Проверить размер файла:
```bash
wc -l /var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/Handlers/ProjectHandler.php
```

**Ожидаемый результат**: Примерно 600-700 строк (если файл правильно обновлён).

---

## Шаг 4: Проверить логи В РЕАЛЬНОМ ВРЕМЕНИ

Открыть 2 терминала на сервере.

**Терминал 1** - смотрим логи PHP-FPM:
```bash
sudo tail -f /var/log/php8.3-fpm.log
```

**Терминал 2** - смотрим логи Nginx:
```bash
sudo tail -f /var/log/nginx/error.log
```

**Теперь нажми кнопку "Простой отчёт" в боте.**

Смотри, что появляется в логах.

---

## Шаг 5: Искать DEBUG логи

```bash
sudo grep -r "DEBUG_SIMPLE_REPORT" /var/log/nginx/ | tail -20
sudo grep -r "DEBUG_SIMPLE_REPORT" /var/log/php8.3-fpm.log | tail -20
```

**Если логи есть**: Отправь их мне, я увижу где проблема.

**Если логов НЕТ**: Значит код не выполняется → возвращаемся к Шагу 1 и 2.

---

## Шаг 6: Проверить права доступа к файлам

```bash
sudo chown -R www-data:www-data /var/www/api.ladyzenko.pro/tg/ozna/
sudo chmod -R 755 /var/www/api.ladyzenko.pro/tg/ozna/
```

---

## Шаг 7: Последняя проверка - содержимое файла

Проверить, что в файле ProjectHandler.php есть нужный код:

```bash
grep -n "proj_report_simple" /var/www/api.ladyzenko.pro/tg/ozna/CustomCommands/Handlers/ProjectHandler.php
```

**Ожидаемый результат**: Должно показать несколько строк с номерами, где упоминается "proj_report_simple".

**Если НЕ показывает**: Файл НЕ обновлён на сервере!

---

## ⚡ БЫСТРОЕ РЕШЕНИЕ (скорее всего это поможет):

Выполни эти 3 команды по очереди:

```bash
sudo systemctl restart php8.3-fpm
sudo chown -R www-data:www-data /var/www/api.ladyzenko.pro/tg/ozna/
sudo chmod -R 755 /var/www/api.ladyzenko.pro/tg/ozna/
```

**Затем попробуй кнопку ещё раз.**

---

## Важно:

**90% вероятность** - проблема в том, что PHP-FPM не перезапустили после загрузки файлов. Старый код всё ещё в памяти.

**Решение**: Перезапустить PHP-FPM (первая команда в "Быстром решении").
