# Исправление ошибки "неизвестная команда табеля" для кнопок пусконаладочных работ

## Описание проблемы

Пользователь сообщил, что в активности "Электрооборудование" кнопки:
- "Комплексное опробование" 
- "Режимная наладка"
- "Подготовка к служебной поездке"
- "Дорога"
- "Инструктаж" 
- "Сдача авансового отчета"

формируют отчет и показывают кнопки подтверждения, но при нажатии кнопки "Да" отчет не отправляется и появляется надпись "неизвестная команда табеля".

## Причина проблемы

Проблема заключалась в том, что кнопки подтверждения создают callback-и вида `cat_ТабКомплОпр_yes`, `cat_ТабРежНал_yes` и т.д., но эти callback-и не были правильно обработаны в методах `isActivityExecution()` и `handleActivityExecution()` класса `TabelHandler`.

Система правильно показывала диалог подтверждения, но когда пользователь нажимал "Да", система не могла сопоставить короткие callback-и с соответствующими типами активностей.

## Решение

### 1. Обновлен метод `isActivityExecution()` в `TabelHandler.php`

Добавлено сопоставление коротких callback-ов пусконаладочных работ:

```php
// Handle short callback format for commissioning works
if (preg_match('/^cat_(.+)_yes$/', $category, $matches)) {
    $shortActivityKey = $matches[1];
    // Map of short callback keys to full activity types for commissioning works
    $shortCommissioningCallbacks = [
        'ТабПНРаботы' => 'ПусконаладочныеРаботы',
        'ТабКомплОпр' => 'КомплексноеОпробование',
        'ТабРежНал' => 'РежимнаяНаладка',
        'ТабПодгПоезд' => 'ПодготовкаКПоездке',
        'ТабДорога' => 'Дорога',
        'ТабИнстр' => 'Инструктаж',
        'ТабСдачаОтч' => 'СдачаАвансовогоОтчета',
        'ТабОхрСигн' => 'ОхраннаяСигнализация',
        'ТабОтоплВент' => 'ОтоплениеИВентиляция',
        'ТабТехОб' => 'ТехнологическоеОборудование',
        'ТабМетрол' => 'Метрология'
    ];
    
    if (isset($shortCommissioningCallbacks[$shortActivityKey])) {
        error_log("TabelHandler: isActivityExecution returning true for short commissioning works: {$shortActivityKey}");
        return true;
    }
}
```

### 2. Обновлен метод `handleActivityExecution()` в `TabelHandler.php`

Добавлено извлечение типов активностей из коротких callback-ов:
