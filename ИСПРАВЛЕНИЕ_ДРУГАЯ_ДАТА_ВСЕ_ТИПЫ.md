# Исправление: "Другая дата" для всех типов работ ✅

## Проблема
1. **Первая проблема**: После выбора "Другая дата" для Текущей деятельности система показывала список проектов вместо видов деятельности.

2. **Вторая проблема**: После исправления Текущая деятельность работала правильно, но ШМР, ПНР и Мобильная бригада стали показывать виды Текущей деятельности вместо выбора проекта.

## Причина
Было **ТРИ уровня** проблемы:
1. **TabelHandler** терял контекст при выборе "Другая дата"
2. **GenericmessageCommand** всегда переходил к выбору проекта
3. **Неполное управление флагами**: Не устанавливались флаги для других типов работ

## Решение
Внесены изменения в два файла:

### 1. TabelHandler.php
- **handleDateSelection()**: Устанавливает правильные флаги для каждого типа работ
- **handleCustomDateInput()**: Пропускает выбор проекта для Текущей деятельности

### 2. GenericmessageCommand.php
- **handleDateInput()**: Проверяет ВСЕ флаги и делегирует ТОЛЬКО для Текущей деятельности

## Результат

### Текущая деятельность:
✅ Показывает виды деятельности (БЕЗ списка проектов)

### Другие типы (ШМР, ПНР, Мобильная бригада):
✅ Показывает список проектов (как и должно быть)
