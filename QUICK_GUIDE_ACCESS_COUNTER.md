# Краткая инструкция: Счетчик заявок на доступ

## Что было исправлено
Кнопка "👥 Заявки на доступ" в админ-панели теперь показывает количество заявок в скобках.

## Как это выглядит

### До исправления:
```
⚙️ Панель администратора

[📋 Управление проектами]
[👥 Заявки на доступ]          ← Нет счетчика
[🔔 Проекты на согласование (3)]
```

### После исправления:
```
⚙️ Панель администратора

[📋 Управление проектами]
[👥 Заявки на доступ (4)]      ← Есть счетчик!
[🔔 Проекты на согласование (3)]
```

## Как проверить

1. Откройте Telegram бот
2. Перейдите в "⚙️ Админка"
3. Посмотрите на кнопку "👥 Заявки на доступ"
4. Если есть pending заявки, вы увидите число в скобках

## Для разработчиков

### Измененный файл:
- `CustomCommands/Handlers/AdminHandler.php` (метод `showAdminMainMenu`)

### Ключевой код:
```php
$databaseService = $this->adminService->getDatabaseService();
$accessRequestsCount = count($databaseService->getPendingAccessRequests());

$accessButtonText = '👥 Заявки на доступ';
if ($accessRequestsCount > 0) {
    $accessButtonText .= " ({$accessRequestsCount})";
}
```

### Тестовые скрипты:
```bash
# Проверить счетчик
php test_access_requests_counter.php

# Проверить таблицу заявок
php check_access_requests_table.php
```

## Примечания
- Счетчик показывает только заявки со статусом "pending"
- Обработанные заявки (approved/rejected) не учитываются
- При ошибке БД кнопка отображается без счетчика (для стабильности)
