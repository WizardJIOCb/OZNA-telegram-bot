# Обновление фильтров активностей - 20.10.2025

## Изменения

### ❌ Добавлены в НЕРАБОЧИЕ активности

Следующие активности теперь **НЕ учитываются** при определении статуса "на объекте":

1. **📋 Разработка программы работ** - планирование, офисная работа
2. **📅 Разработка графика работ** - планирование, офисная работа

### ✅ Подтверждено: Простои - это РАБОЧИЕ активности

**Любой вид простоя** остается рабочей активностью:
- ⚠️ ⏸️ Простой (по любой причине)
- Сотрудник находится на объекте и ожидает
- Это РАБОЧЕЕ время, даже если не ведется активная работа

## Технические изменения

### Файл: `PersonnelService.php`

**Метод `isWorkActivity()`:**
```php
// Добавлены новые фильтры:
if (strpos($message, 'Разработка программы работ') !== false) return false;
if (strpos($message, 'Разработка графика работ') !== false) return false;
```

**Методы `findContinuousWorkSession()` и `findStoppedWorkSession()`:**
- Исправлена критическая ошибка
- Теперь проверяется последняя **РАБОЧАЯ** активность, а не любая запись
- Офисные активности после работы больше не продлевают статус "на объекте"

### Пример исправления бага

**ДО исправления:**
```
Сотрудник:
  09.10 - Работы по графику (реальная работа)
  17.10 - Разработка программы работ (офис)
  
Результат: НА ОБЪЕКТЕ ❌ (неправильно!)
Причина: последняя запись 17.10 < 3 дней назад
```

**ПОСЛЕ исправления:**
```
Сотрудник:
  09.10 - Работы по графику (реальная работа)
  17.10 - Разработка программы работ (офис)
  
Результат: НЕ на объекте ✅ (правильно!)
Причина: последняя РАБОТА 09.10 > 3 дней назад
```
