## 📝 Структура таблицы project_moderation

```
id                  INT AUTO_INCREMENT PRIMARY KEY
project_code        VARCHAR(50)  - Код проекта
original_name       VARCHAR(255) - Оригинальное название
current_name        VARCHAR(255) - Текущее название
status              ENUM('pending', 'active', 'renamed', 'rejected')
added_by            INT - ID пользователя
added_at            DATETIME
moderated_by        INT - ID модератора
moderated_at        DATETIME
moderation_comment  TEXT
is_active           BOOLEAN
```

2. 🆕 Добавить новый проект
