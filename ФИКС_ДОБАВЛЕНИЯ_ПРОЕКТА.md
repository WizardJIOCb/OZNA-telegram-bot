# ПРОБЛЕМА С ДОБАВЛЕНИЕМ ПРОЕКТА - РЕШЕНА

## Что было не так

Когда пользователь нажимал на кнопку "Добавить проект" и вводил название (например, "ТЕСТ"), ничего не происходило.

### Причина

В коде ProjectModerationHandler при установке состояния ожидания ввода названия проекта **не очищались старые состояния** из предыдущих операций пользователя.

У пользователя в базе данных оставалось старое состояние:
```
[state] => awaiting_custom_idle_reason
```

Это состояние конфликтовало с новым состоянием добавления проекта.

## Что было исправлено

### Файл: `CustomCommands/Handlers/ProjectModerationHandler.php`

В методе `startAddingNewProject()` добавлена очистка старых состояний:

```php
// БЫЛО:
$conversation->notes['project_mod_action'] = 'add_new';
$conversation->update();

// СТАЛО:
// Clear any old states first
$conversation->notes['state'] = null;
$conversation->notes['awaiting_custom_input'] = null;
$conversation->notes['awaiting_date_input'] = null;
$conversation->notes['awaiting_fio_input'] = null;
$conversation->notes['admin_action'] = null;

// Set conversation state for project moderation
$conversation->notes['project_mod_action'] = 'add_new';
$conversation->update();

error_log("ProjectModerationHandler: Set state 'add_new' for user {$userId}, cleared old states");
```

## Технические детали

### Как работает механизм:

1. **Нажатие кнопки "Добавить проект":**
   - CallbackqueryCommand получает callback `proj_mod_add_new`
   - Передает в ProjectModerationHandler
   - ProjectModerationHandler очищает старые состояния
   - Устанавливает `project_mod_action = 'add_new'`
   - Отправляет пользователю сообщение с просьбой ввести название

2. **Ввод текста (название проекта):**
   - GenericmessageCommand получает текстовое сообщение
   - Читает conversation с ключом '/callback'
   - Проверяет `project_mod_action`
   - Если `project_mod_action = 'add_new'`, вызывает ProjectModerationHandler.processNewProjectName()
   - Обрабатывает название проекта

3. **Обработка названия:**
   - Валидация длины (3-50 символов)
   - Проверка на существование проекта
   - Добавление в базу данных как "pending" (ожидающий модерации)
   - Отправка уведомлений администраторам
   - Подтверждение пользователю
