🚀 КАК ИСПОЛЬЗОВАТЬ:

1. Пользователь нажимает "Табель" в главном меню
2. Выбирает "Текущая деятельность" из списка видов работ
3. Выбирает дату (Сегодня или Вчера)
4. Выбирает проект из списка (ОИ834, ОИ651, и т.д.)
5. Появляется меню "💼 Табель - Текущая деятельность для проекта {код}"
6. Пользователь видит 4 новые кнопки:
   - 🏥 Медицинский осмотр
   - 📋 Аттестация
   - 📝 Подготовка материала к ТКП
   - 📊 Общая
7. Нажимает на нужную кнопку
8. Подтверждает действие (Да/Нет)
9. Запись сохраняется в табель и отправляется в общий чат

🔄 ПОТОК ДАННЫХ:

Табель → Текущая деятельность → Дата → Проект → Тип активности → Подтверждение → Сохранение
