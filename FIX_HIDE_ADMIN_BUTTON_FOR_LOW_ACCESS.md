# ИЗМЕНЕНИЕ: Скрыта кнопка "Админка" для пользователей с низким уровнем доступа

## Дата изменения
2025-10-12

## Описание изменения
Кнопка "⚙️ Админка" теперь отображается только для пользователей с уровнем доступа 2 и выше (Супервайзер, Администратор, Суперадминистратор). Гости (уровень 0) и обычные пользователи (уровень 1) больше не видят эту кнопку в главном меню.

## Обоснование

### Было:
- **Все пользователи** видели кнопку "⚙️ Админка" в главном меню
- При нажатии пользователи без прав получали сообщение об отказе в доступе
- Это создавало путаницу и лишние действия

### Стало:
- **Только администраторы** (уровень 2+) видят кнопку "⚙️ Админка"
- Гости и обычные пользователи вообще не видят кнопку
- Интерфейс стал чище и понятнее
- Меньше вопросов от пользователей "почему я не могу зайти в админку?"

## Уровни доступа

| Уровень | Название | Видит кнопку "Админка"? |
|---------|----------|------------------------|
| 0 | Гость | ❌ НЕТ |
| 1 | Пользователь | ❌ НЕТ |
| 2 | Супервайзер | ✅ ДА |
| 3 | Администратор | ✅ ДА |
| 4 | Суперадминистратор | ✅ ДА |

## Внесённые изменения

### 1. Файл: `CustomCommands/Services/MessageService.php`

**Метод `createMainMenuReplyKeyboard()`**:

**Было**:
```php
public function createMainMenuReplyKeyboard(): array
{
    return [
        [
            ['text' => '📊 Табель'], 
            ['text' => '❓ Помощь']
        ],
        [
            ['text' => '👤 Профиль'], 
            ['text' => '📁 Проекты']
        ],
        [
            ['text' => '⚙️ Админка']  // ❌ Всегда показывалась
        ]
    ];
}
```

**Стало**:
```php
public function createMainMenuReplyKeyboard(int $userAccessLevel = 99): array
{
    $keyboard = [
        [
            ['text' => '📊 Табель'], 
            ['text' => '❓ Помощь']
        ],
        [
            ['text' => '👤 Профиль'], 
            ['text' => '📁 Проекты']
        ]
    ];
    
    // Add Админка button only for users with access level 2 or higher
    if ($userAccessLevel >= 2) {
        $keyboard[] = [
            ['text' => '⚙️ Админка']
        ];
    }
    
    return $keyboard;
}
```

**Изменения**:
- Добавлен параметр `$userAccessLevel` (по умолчанию 99 для обратной совместимости)
- Кнопка "⚙️ Админка" добавляется только если уровень >= 2

## Преимущества изменения

1. **Улучшение UX**:
   - Пользователи не видят недоступные им функции
   - Меньше путаницы и вопросов

2. **Чистота интерфейса**:
   - Меню показывает только релевантные для пользователя опции
   - Не загромождается лишними кнопками

3. **Безопасность**:
   - Скрытие административных функций от обычных пользователей
   - Меньше попыток несанкционированного доступа

4. **Логичность**:
   - Соответствует принципу "показывать только то, что доступно"
   - Более профессиональный подход к разработке интерфейса

## Обратная совместимость

Параметр `$userAccessLevel` имеет значение по умолчанию `99`, поэтому:
- Старый код без передачи параметра продолжит работать
- По умолчанию кнопка будет показываться (безопасное поведение)
- Новый код с явной передачей уровня доступа работает корректно
