## 🎯 Логика "На объекте"

### Визуализация сессий работы

```
Таймлайн записей пользователя:
═══════════════════════════════════════════════════════════

  01.08  05.08  10.08  15.08  20.08  25.08  30.08  05.09
    │      │      │      │      │      │      │      │
    ●      ●      ●      ●              ●      ●      ●
    
    └──────┴──────┴──────┘              └──────┴──────┘
      Старая сессия         >3 дня       Текущая сессия
     (завершена)          без записей    (активна)

Результат:
- Первая запись текущей сессии: 25.08
- Длительность: СЕГОДНЯ - 25.08 = X дней
- Индикатор: 🟢/🟡/🔴 в зависимости от X
```

### Пороги индикаторов

```
Дни на объекте:
0────────30────────45────────60+
🟢        🟢        🟡         🔴
Норма   Предел   Внимание   Критично
```

## 🏖️ Логика "Свободная вахта"

### Поиск продолжительной работы

```
Записи пользователя (от новых к старым):
═══════════════════════════════════════

Сегодня
  │
  ├─ (нет записей 7 дней)
  │
  └─ 12.10  Последняя запись ◄─── ПОСЛЕДНЯЯ ЗАПИСЬ
     11.10  Работа
     10.10  Работа
     09.10  Работа  } >4 дней подряд
     08.10  Работа  } = продолжительная работа
     07.10  Работа
     
     (перерыв >1 дня)
     
     01.10  Старая работа

Результат:
- Последняя продолжительная работа: 12.10
- Длительность отдыха: СЕГОДНЯ - 12.10 = 7 дней
- Индикатор: 🔴 (мало отдохнул)
```

### Пороги индикаторов (ИНВЕРТИРОВАНЫ!)

```
Дни отдыха:
0────────14────────30────────60+
🔴        🔴        🟡         🟢
Мало     Недостаточно  Хорошо   Отлично

Примечание: Инверсия нужна, чтобы показать,
кому СРОЧНО нужен отдых!
```

## 🎨 Цветовая схема индикаторов

### На объекте

```
🟢 ЗЕЛЕНЫЙ (0-30 дней)
├─ Описание: Оптимальное время на объекте
├─ Действие: Нет
└─ Приоритет: Низкий

🟡 ЖЕЛТЫЙ (31-45 дней)
├─ Описание: Длительное пребывание
├─ Действие: Рекомендуется планировать ротацию
└─ Приоритет: Средний

🔴 КРАСНЫЙ (46+ дней)
├─ Описание: Критическое время на объекте
├─ Действие: Требуется срочная ротация
└─ Приоритет: Высокий
```

### Свободная вахта (ИНВЕРТИРОВАНО)

```
🔴 КРАСНЫЙ (0-14 дней)
├─ Описание: Недостаточный отдых
├─ Действие: НЕ отправлять на объект
└─ Приоритет: Высокий

🟡 ЖЕЛТЫЙ (15-30 дней)
├─ Описание: Умеренный отдых
├─ Действие: Можно планировать выход
└─ Приоритет: Средний

🟢 ЗЕЛЕНЫЙ (31+ дней)
├─ Описание: Хороший отдых
├─ Действие: Готов к работе
└─ Приоритет: Низкий
```

## 📅 Примеры расчетов

### Сценарий 1: Непрерывная работа

```
Сегодня: 19.10.2025

Записи в табеле:
- 19.10.2025 ✅
- 18.10.2025 ✅
- 17.10.2025 ✅
- ...
- 01.10.2025 ✅ ← Первая запись сессии

Расчет:
- Длительность: 19.10 - 01.10 = 18 дней
- Индикатор: 🟢 (≤30 дней)
- Отображение: "🟢 Иванов И.И. - 18 дней"
```

### Сценарий 2: Работа с перерывом

```
Сегодня: 19.10.2025

Записи в табеле:
- 19.10.2025 ✅
- 18.10.2025 ✅
- 17.10.2025 ✅
- 16.10.2025 ✅
- 15.10.2025 ✅ ← Текущая сессия
- 14.10.2025 ❌
- 13.10.2025 ❌
- 12.10.2025 ❌
- 11.10.2025 ❌ >3 дня без записей
- 10.10.2025 ✅ ← Старая сессия

Расчет:
- Начало сессии: 15.10.2025
- Длительность: 19.10 - 15.10 = 4 дня
- Индикатор: 🟢 (≤30 дней)
```

### Сценарий 3: Свободная вахта

```
Сегодня: 19.10.2025

Последние записи:
- 19.10.2025 ❌ нет
- ...
- 12.10.2025 ❌ нет (7 дней без записей)
- ...
- 05.10.2025 ✅
- 04.10.2025 ✅
- 03.10.2025 ✅
- 02.10.2025 ✅
- 01.10.2025 ✅ ← 5 дней подряд = продолжительная работа

Расчет:
- Свободная вахта с: 05.10.2025
- Длительность отдыха: 19.10 - 05.10 = 14 дней
- Индикатор: 🔴 (≤14 дней, мало отдохнул)
```
