# Концепция системы пользовательского добавления проектов с модерацией

## 📋 Описание проблемы

### Текущая ситуация
1. **Проблема доступности**: Проекты иногда пропадают после перезагрузки бота
2. **Зависимость от администраторов**: Пользователям приходится ждать администраторов для добавления новых проектов
3. **Риск некорректного ввода**: Если дать полную свободу пользователям, есть риск добавления проектов с неправильными названиями
4. **Отсутствие стандартизации**: Нет механизма контроля соответствия названий проектов корпоративным стандартам

### Текущая архитектура
- **Хранение проектов**: `data/projects.json` + таблица БД `project`
- **Источник данных**: `AdminService` загружает проекты из обоих источников
- **Добавление проектов**: Только через админ-панель (уровень доступа ≥ 2)
- **Использование проектов**: При создании записей табеля пользователи выбирают из списка

---

## 🎯 Предложенное решение

### Концепция двухэтапной системы
Создание системы, где пользователи могут самостоятельно добавлять проекты в базу и сразу начинать с ними работать, а администраторы получают уведомления и могут проверить/скорректировать названия проектов.

### Преимущества подхода
1. ✅ **Автономность пользователей**: Не нужно ждать администратора
2. ✅ **Контроль качества**: Администраторы могут проверить и исправить
3. ✅ **Отслеживаемость**: История добавления и изменений проектов
4. ✅ **Минимизация ошибок**: Все изменения администратора автоматически применяются к существующим записям

## 🏗️ Архитектура решения

### 1. Статусы проектов

```
PENDING        - Проект добавлен пользователем, ожидает модерации
ACTIVE         - Проект одобрен администратором (или автоодобрен)
RENAMED        - Проект переименован администратором
REJECTED       - Проект отклонён администратором
```

### 2. Структура данных

#### 2.1 Расширение таблицы `project` в БД

```sql
CREATE TABLE IF NOT EXISTS project_moderation (
    id INT AUTO_INCREMENT PRIMARY KEY,
    project_code VARCHAR(50) NOT NULL,
    original_name VARCHAR(255),
    current_name VARCHAR(255) NOT NULL,
    status ENUM('pending', 'active', 'renamed', 'rejected') DEFAULT 'pending',
    added_by INT NOT NULL,
    added_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    moderated_by INT NULL,
    moderated_at DATETIME NULL,
    moderation_comment TEXT NULL,
    is_active BOOLEAN DEFAULT 1,
    INDEX idx_status (status),
    INDEX idx_added_by (added_by),
    INDEX idx_project_code (project_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 2.2 Файловое хранилище (резервное)

`data/pending_projects.json` - для случаев недоступности БД:
```json
[
  {
```

### 3. Логика работы системы

#### 3.1 Добавление проекта пользователем

**Точка входа**: `📂 Мои проекты` → `📋 Проекты для отчёта` → `➕ Добавить проект`

**Новый пункт меню**: `➕ Добавить новый проект`

**Процесс**:
1. Пользователь нажимает "➕ Добавить новый проект"
2. Бот запрашивает название проекта (текстовый ввод)
3. Валидация названия:
   - Не пустое
   - Длина 3-50 символов
   - Латиница/кириллица/цифры/дефис
   - Проверка на дубликаты (нечувствительно к регистру)
4. Проект добавляется в БД со статусом `pending`
5. Проект сразу доступен пользователю для работы
6. Уведомление администраторам

#### 3.2 Модерация администратором

**Точка входа**: `⚙️ Админка` → `📋 Проекты на согласование`

**Интерфейс модерации**:
```
📋 Проекты на согласование

🔔 У вас 3 проекта ожидают проверки:

1️⃣ ОИ999
   Добавил: Иван Иванов (@username)
   Дата: 14.10.2025 10:30
   [✅ Одобрить] [✏️ Переименовать] [❌ Отклонить]

2️⃣ бкнс-150
   Добавил: Пётр Петров (@username2)
   Дата: 14.10.2025 11:15
   [✅ Одобрить] [✏️ Переименовать] [❌ Отклонить]
```

**Действия администратора**:

1. **✅ Одобрить**:
   - Статус → `active`
   - Проект остаётся в системе без изменений
   - Уведомление пользователю: "Ваш проект ОИ999 одобрен"

2. **✏️ Переименовать**:
   - Запрос нового названия
   - Статус → `renamed`
   - **Автоматическое обновление всех записей табеля** с этим проектом
   - Уведомление пользователю: "Ваш проект ОИ999 переименован в ОИ-999"

3. **❌ Отклонить**:
   - Запрос причины отклонения
   - Статус → `rejected`
   - **Проект скрывается** из списка доступных
   - **Записи табеля остаются** (для истории)
   - Уведомление пользователю: "Ваш проект ОИ999 отклонён. Причина: не соответствует стандарту наименования"

## 🔒 Безопасность и валидация

### Валидация ввода

**Правила для названия проекта**:
```php
function validateProjectName(string $name): array {
    $errors = [];
    
    // Проверка длины
    if (mb_strlen($name) < 3 || mb_strlen($name) > 50) {
        $errors[] = "Название должно быть от 3 до 50 символов";
    }
    
    // Проверка на разрешённые символы
    if (!preg_match('/^[A-Za-zА-Яа-яЁё0-9\-_\s]+$/u', $name)) {
        $errors[] = "Название может содержать только буквы, цифры, дефис и подчёркивание";
    }
    
    // Проверка на дубликаты (case-insensitive)
    if (projectExists($name)) {
        $errors[] = "Проект с таким названием уже существует";
    }
    
    return $errors;
}
```

### Ограничения

1. **Частота добавления**: Не более 5 проектов в день на пользователя
2. **Защита от спама**: Интервал 5 минут между добавлениями
3. **Проверка прав**: Только пользователи с уровнем ≥ 1 (не гости)

## ⚠️ Риски и их митигация

### Риск 1: Спам проектами
**Проблема**: Пользователи могут добавлять множество некорректных проектов

**Митигация**:
- Лимит 5 проектов в день на пользователя
- Интервал 5 минут между добавлениями
- Автоматическое блокирование при злоупотреблении

### Риск 2: Отставание модерации
**Проблема**: Администраторы не успевают проверять проекты

**Митигация**:
- Push-уведомления администраторам
- Эскалация (напоминания через 24 часа)
- Автоодобрение проектов от доверенных пользователей (опционально)

### Риск 3: Потеря данных при переименовании
**Проблема**: Ошибка при массовом обновлении записей

**Митигация**:
- Транзакции БД (rollback при ошибке)
- Логирование всех изменений
- Резервное копирование перед массовым обновлением

### Риск 4: Конфликты названий
**Проблема**: Два пользователя одновременно добавляют проект с одинаковым названием

**Митигация**:
- Проверка на уникальность при добавлении
- Блокировка на уровне БД (UNIQUE constraint)
- Понятное сообщение об ошибке

### SQL-запросы

#### Добавление проекта
```sql
INSERT INTO project_moderation 
(project_code, original_name, current_name, status, added_by, added_at) 
VALUES (?, ?, ?, 'pending', ?, NOW())
```

#### Получение проектов на модерации
```sql
SELECT pm.*, 
       od.data->>'$.fio' as user_fio,
       (SELECT COUNT(*) FROM tabel WHERE project_code = pm.current_name) as tabel_count
FROM project_moderation pm
LEFT JOIN ozna_data od ON pm.added_by = od.user_id
WHERE pm.status = 'pending'
ORDER BY pm.added_at ASC
```

#### Одобрение проекта
```sql
UPDATE project_moderation 
SET status = 'active', 
    moderated_by = ?, 
    moderated_at = NOW() 
WHERE id = ?
```

### Методы DatabaseService (расширение)

```php
class DatabaseService {
    
    /**
     * Добавить проект на модерацию
     */
    public function addPendingProject(string $projectCode, int $userId): bool|int
    {
        $query = "INSERT INTO project_moderation 
                  (project_code, original_name, current_name, status, added_by, added_at) 
                  VALUES (?, ?, ?, 'pending', ?, NOW())";
        
        $stmt = $this->getConnection()->prepare($query);
        $stmt->bind_param("sssi", $projectCode, $projectCode, $projectCode, $userId);
        
        if ($stmt->execute()) {
            return $this->getConnection()->insert_id;
        }
        
        return false;
    }
    
    /**
     * Получить проекты на модерации
     */
    public function getPendingProjects(): array
    {
        $query = "SELECT pm.*, 
                         od.data->>'$.fio' as user_fio,
                         (SELECT COUNT(*) FROM tabel WHERE project_code = pm.current_name) as tabel_count
                  FROM project_moderation pm
                  LEFT JOIN ozna_data od ON pm.added_by = od.user_id
                  WHERE pm.status = 'pending'
                  ORDER BY pm.added_at ASC";
        
        $result = $this->getConnection()->query($query);
        $projects = [];
        
        while ($row = $result->fetch_assoc()) {
            $projects[] = $row;
        }
        
        return $projects;
    }
    
    /**
     * Одобрить проект
     */
    public function approveProject(int $projectId, int $moderatorId): bool
    {
        $query = "UPDATE project_moderation 
                  SET status = 'active', 
                      moderated_by = ?, 
                      moderated_at = NOW() 
                  WHERE id = ?";
        
        $stmt = $this->getConnection()->prepare($query);
        $stmt->bind_param("ii", $moderatorId, $projectId);
        
        return $stmt->execute();
    }
    
    /**
     * Переименовать проект и обновить все записи
     */
    public function renameProject(int $projectId, string $newName, int $moderatorId, string $comment = ''): bool
    {
        // Начинаем транзакцию
        $this->getConnection()->begin_transaction();
        
        try {
            // Получаем старое название
            $query = "SELECT current_name FROM project_moderation WHERE id = ?";
            $stmt = $this->getConnection()->prepare($query);
            $stmt->bind_param("i", $projectId);
            $stmt->execute();
            $result = $stmt->get_result();
            $oldName = $result->fetch_assoc()['current_name'];
            
            // Обновляем проект
            $query = "UPDATE project_moderation 
                      SET current_name = ?, 
                          status = 'renamed', 
                          moderated_by = ?, 
                          moderated_at = NOW(),
                          moderation_comment = ? 
                      WHERE id = ?";
            
            $stmt = $this->getConnection()->prepare($query);
            $stmt->bind_param("sisi", $newName, $moderatorId, $comment, $projectId);
            $stmt->execute();
            
            // Обновляем все записи табеля
            $query = "UPDATE tabel SET project_code = ? WHERE project_code = ?";
            $stmt = $this->getConnection()->prepare($query);
            $stmt->bind_param("ss", $newName, $oldName);
            $stmt->execute();
            
            // Фиксируем транзакцию
            $this->getConnection()->commit();
            
            return true;
            
        } catch (\Exception $e) {
            // Откатываем при ошибке
            $this->getConnection()->rollback();
            error_log("Error renaming project: " . $e->getMessage());
            return false;
        }
    }
    
    /**
     * Отклонить проект
     */
    public function rejectProject(int $projectId, int $moderatorId, string $reason): bool
    {
        $query = "UPDATE project_moderation 
                  SET status = 'rejected', 
                      moderated_by = ?, 
                      moderated_at = NOW(),
                      moderation_comment = ?,
                      is_active = 0
                  WHERE id = ?";
        
        $stmt = $this->getConnection()->prepare($query);
        $stmt->bind_param("isi", $moderatorId, $reason, $projectId);
        
        return $stmt->execute();
    }
    
    /**
     * Проверить, существует ли проект с таким названием
     */
    public function projectExists(string $projectCode): bool
    {
        $query = "SELECT COUNT(*) as count 
                  FROM project_moderation 
                  WHERE LOWER(current_name) = LOWER(?) 
                  AND status IN ('pending', 'active', 'renamed')
                  AND is_active = 1";
        
        $stmt = $this->getConnection()->prepare($query);
        $stmt->bind_param("s", $projectCode);
        $stmt->execute();
        $result = $stmt->get_result();
        $row = $result->fetch_assoc();
        
        return $row['count'] > 0;
    }
    
    /**
     * Получить проекты пользователя (включая pending)
     */
    public function getUserProjects(int $userId): array
    {
        $query = "SELECT current_name as project_code, status 
                  FROM project_moderation 
                  WHERE (added_by = ? AND status IN ('pending', 'active', 'renamed'))
                     OR status IN ('active', 'renamed')
                  AND is_active = 1
                  ORDER BY added_at DESC";
        
        $stmt = $this->getConnection()->prepare($query);
        $stmt->bind_param("i", $userId);
        $stmt->execute();
        $result = $stmt->get_result();
        
        $projects = [];
        while ($row = $result->fetch_assoc()) {
            $projects[] = $row;
        }
        
        return $projects;
    }
    
    /**
     * Получить количество проектов на модерации
     */
    public function getPendingProjectsCount(): int
    {
        $query = "SELECT COUNT(*) as count 
                  FROM project_moderation 
                  WHERE status = 'pending'";
        
        $result = $this->getConnection()->query($query);
        $row = $result->fetch_assoc();
        
        return (int)$row['count'];
    }
}
```

## 🎓 Обучение пользователей

### Для обычных пользователей

**Инструкция "Как добавить новый проект"**:

1. Откройте меню "📂 Мои проекты"
2. Выберите "📋 Проекты для отчёта"
3. Нажмите "🆕 Добавить новый проект"
4. Введите название проекта (например: ОИ834)
5. Подтвердите добавление
6. Проект сразу доступен для работы!
7. Дождитесь проверки администратором (обычно в течение 24 часов)

### Для администраторов

**Инструкция "Модерация проектов"**:

1. Откройте "⚙️ Админка"
2. Выберите "🔔 Проекты на согласование"
3. Просмотрите список проектов
4. Для каждого проекта выберите действие:
   - **✅ Одобрить** - если название корректно
   - **✏️ Переименовать** - если нужно исправить название
   - **❌ Отклонить** - если проект некорректный
5. При переименовании укажите правильное название и причину
6. При отклонении укажите причину отказа
