## 🎯 Обзор

Интеграция с **xAI Grok** добавляет в бота мощные AI-функции:

### ✨ 5 основных возможностей:

1. **📊 Анализ проектов** - AI анализирует отчеты и дает рекомендации
2. **💡 Паттерны в заметках** - Выявляет повторяющиеся проблемы
3. **🎯 Прогноз загрузки** - Предсказывает нехватку ресурсов
4. **📄 Executive Summary** - Создает краткие отчеты для руководства
5. **❓ AI-Ассистент** - Отвечает на вопросы о проектах

## 🚀 Установка и настройка

### Шаг 1: Получить API ключ

1. Зайди на https://console.x.ai/
2. Войди в свой аккаунт xAI
3. Создай новый API ключ
4. Скопируй его

### Шаг 2: Настроить конфигурацию

Открой файл `grok_config.php` и вставь свой API ключ:

```php
return [
    'grok_api_key' => 'xai-ТВОЙ_КЛЮЧ_ЗДЕСЬ',  // ← Вставь сюда
    // ... остальные настройки
];
```

### Шаг 3: Зарегистрировать Handler

В файле `CustomCommands/Services/CallbackHandlerFactory.php` добавь:

```php
use Longman\TelegramBot\Commands\SystemCommands\Handlers\GrokHandler;

// В методе registerHandlers():
$this->handlers[] = new GrokHandler(
    $this->databaseService,
    $this->messageService,
    $adminService
);
```

### Шаг 4: Добавить кнопку в меню (опционально)

В `CustomCommands/Handlers/MainMenuHandler.php` добавь кнопку для доступа:

```php
// Для супервайзеров и выше
if ($userAccessLevel >= 2) {
    $keyboard[] = [
        ['text' => '🤖 Grok AI', 'callback_data' => 'category_Grok']
    ];
}
```

### Шаг 5: Проверить работу

Отправь боту:
```
/start → 🤖 Grok AI
```

Если видишь меню с AI-функциями — всё работает! ✅

## 💡 Возможности

### 1. 📊 Анализ проектов

**Что делает:**
- Собирает данные по проекту за период
- Анализирует активности и время
- Выявляет проблемы
- Дает рекомендации
- Прогнозирует завершение

**Пример результата:**
```
📊 АНАЛИЗ ПРОЕКТА XXX

ОСНОВНЫЕ НАБЛЮДЕНИЯ:
✅ За 30 дней выполнено 245 часов работ
✅ Наибольшая активность: монтаж электрооборудования (85ч)
✅ Участвовало 8 сотрудников

⚠️ ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ:
- Высокий процент простоев (12%)
- Неравномерное распределение загрузки
- Задержки на этапе наладки

🎯 РЕКОМЕНДАЦИИ:
1. Пересмотреть график монтажа
2. Добавить 2 монтажников на пиковый период
3. Провести дополнительный инструктаж по наладке

📅 ПРОГНОЗ:
При текущих темпах завершение через 14-18 дней
```

---

### 2. 💡 Паттерны в заметках

**Что делает:**
- Анализирует все заметки проекта
- Находит повторяющиеся проблемы
- Выявляет критические замечания
- Дает рекомендации по устранению

**Пример результата:**
```
💡 ПАТТЕРНЫ В ЗАМЕТКАХ (30 дней, 47 заметок)

🔄 ПОВТОРЯЮЩИЕСЯ ПРОБЛЕМЫ:
1. Несоответствие монтажных отверстий (5 случаев)
   → Рекомендация: Проверять чертежи до начала работ
   
2. Отсутствие кабельной продукции (3 случая)
   → Рекомендация: Улучшить планирование поставок

🚨 КРИТИЧЕСКИЕ ЗАМЕЧАНИЯ:
- Повреждение кабеля при монтаже (19.10)
- Проблемы с заземлением шкафа (22.10)

✅ ПОЗИТИВНЫЕ МОМЕНТЫ:
- Успешное испытание оборудования
- Хорошая координация между бригадами

🎯 ПРЕДОТВРАЩЕНИЕ:
Рекомендую создать чек-лист проверки перед монтажом
```

**Пример результата:**

```
🎯 ПРОГНОЗ ЗАГРУЗКИ ПНР (14 дней)

📊 ОЖИДАЕМАЯ ЗАГРУЗКА:

Неделя 2 (30 окт - 5 ноя): СРЕДНЯЯ ✅

📈 ПИКОВЫЕ ПЕРИОДЫ:
- 24-26 октября: пик на проектах XXX, YYY, ZZZ
- 2-3 ноября: активная фаза на объекте AAA

⚠️ РИСКИ НЕХВАТКИ РЕСУРСОВ:
- На 25 октября запланировано 5 объектов одновременно
- Возможна нехватка 2-3 инженеров

🎯 РЕКОМЕНДАЦИИ:
1. Перенести наладку YYY на 27 октября
2. Привлечь 2 сотрудников из резерва на 24-26 окт
```

### 4. 📄 Executive Summary (для руководства)

**Что делает:**
- Превращает технические данные в бизнес-метрики
- Создает краткий отчет для руководства
- Выделяет ключевые моменты

**Как использовать в коде:**
```php
// После экспорта отчета в CSV
$reportData = [...]; // Данные из CSV

$grokService = new GrokService($databaseService);
$result = $grokService->generateExecutiveSummary($reportData);

if ($result['success']) {
    echo $result['summary'];
}
```

**Пример результата:**
```

ОСНОВНЫЕ ПОКАЗАТЕЛИ:

✅ ДОСТИЖЕНИЯ:
✓ Завершен монтаж электрооборудования
✓ Пройдены испытания 1 очереди
✓ Получено одобрение заказчика

⚠️ ПРОБЛЕМЫ:
! Задержка поставки кабеля (5 дней)

🎯 РЕКОМЕНДАЦИИ:
```

## ⚙️ Настройки

### Уровни доступа

В `grok_config.php`:

```php
'min_access_level' => 2,  // Минимальный уровень для AI
```

Уровни:
- 0 = Гость
- 1 = Пользователь
- 2 = Супервайзер ✅
- 3 = Администратор ✅
- 4 = Суперадмин ✅

### Включение/выключение функций

```php
'features' => [
    'project_analysis' => true,    // Вкл/выкл анализ проектов
    'notes_patterns' => true,      // Вкл/выкл анализ заметок
    'resource_prediction' => true, // Вкл/выкл прогноз
    'executive_summary' => true,   // Вкл/выкл executive summary
    'ai_assistant' => true,        // Вкл/выкл ассистента
],
```

### Параметры API

```php
'default_temperature' => 0.7,  // 0.0-1.0, креативность ответов
'default_max_tokens' => 2000,  // Максимум токенов в ответе
```

## 🔒 Безопасность

### Что НЕ отправляется в Grok:
- ❌ Персональные данные пользователей
- ❌ Пароли и токены
- ❌ Финансовые данные

### Что отправляется:
- ✅ Коды проектов (обезличенные)
- ✅ Типы активностей
- ✅ Количество часов
- ✅ Текст заметок (техническая информация)

### Рекомендации:
1. Не включай в заметки конфиденциальную информацию
2. Используй обезличенные коды проектов
3. Регулярно проверяй логи API запросов

## 🐛 Отладка

### Включить логирование:

```php
// В GrokService.php добавь:
error_log("Grok Request: " . json_encode($messages));
error_log("Grok Response: " . $response);
```

### Проверить API ключ:

```bash
curl https://api.x.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_KEY" \
  -d '{"messages": [{"role": "user", "content": "Test"}], "model": "grok-beta"}'
```

### Частые проблемы:

**1. "API key not configured"**
- Проверь `grok_config.php`
- Убедись что ключ не пустой

**2. "API request failed with code 401"**
- Неверный API ключ
- Проверь ключ на console.x.ai

**3. "API request failed with code 429"**
- Превышен лимит запросов
- Подожди минуту и попробуй снова

## 📈 Метрики и мониторинг

### Отслеживание использования:

Создай таблицу для логирования:

```sql
CREATE TABLE grok_usage_log (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    feature VARCHAR(50) NOT NULL,
    input_tokens INT,
    output_tokens INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_feature (feature),
    INDEX idx_created (created_at)
);
```

Добавь логирование в `GrokService`:

```php
private function logUsage(int $userId, string $feature, array $usage): void
{
    $pdo = $this->databaseService->getConnection();
    $sql = "INSERT INTO grok_usage_log (user_id, feature, input_tokens, output_tokens) 
            VALUES (?, ?, ?, ?)";
    $stmt = $pdo->prepare($sql);
    $stmt->execute([
        $userId,
        $feature,
        $usage['prompt_tokens'] ?? 0,
        $usage['completion_tokens'] ?? 0
    ]);
}
```
