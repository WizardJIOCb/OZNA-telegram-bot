### 1.1 PersonnelService.php ✅
**Файл:** `CustomCommands/Services/PersonnelService.php`

**Реализованные методы:**
- `getUsersByFunctionalDirection()` - получение сотрудников по ФН
- `getOnsiteEmployees()` - расчет сотрудников "На объекте"
- `getFreetimeEmployees()` - расчет сотрудников "Свободная вахта"
- `findFirstEntryInCurrentSession()` - поиск начала текущей сессии работ
- `findLastContinuousWorkPeriod()` - поиск последнего продолжительного периода работы
- `getDaysBetween()` - расчет дней между датами
- `getDaysWord()` - склонение слова "день/дня/дней"

**Ключевые особенности:**
- Логика определения сессии работ (перерыв >3 дней)
- Фильтрация записей ЗПИ для свободной вахты
- Цветовые индикаторы по длительности
- Сортировка: "На объекте" - по убыванию, "Свободная вахта" - по возрастанию

## 📝 Примечания

### Особенности реализации:

1. **Маппинг ФН:**
   - `mobile` → `Мобильная бригада`
   - `shmr` → `Шеф-монтаж`
   - `pnr` → `Пусконаладка`

2. **Сессия работ:**
   - Прерывается при отсутствии записей >3 дней
   - Рассчитывается от последней записи назад

3. **Продолжительная работа:**
   - Минимум 5 дней подряд
   - Исключает записи с "ЗПИ" и "Подготовка к служебной поездке"

4. **Цветовые индикаторы:**
   - На объекте: 🟢 0-30, 🟡 31-45, 🔴 46+
   - Свободная вахта: 🔴 0-14, 🟡 15-30, 🟢 31+ (инвертировано!)
