## 👥 Для пользователей

**Добавить проект:**
1. Проекты → Мои проекты → Проекты для отчёта
2. Нажать "🆕 Добавить новый проект"
3. Ввести название (например: ОИ999)
4. Проект сразу доступен!

---

## ⚙️ Для администраторов

**Модерация:**
1. Админка → "🔔 Проекты на согласование (X)"
2. Выбрать проект
3. Действия:
   - ✅ **Одобрить** - название ОК
   - ✏️ **Переименовать** - исправить название (все записи табеля обновятся!)
   - ❌ **Отклонить** - указать причину

## 🔥 Ключевая особенность

При **переименовании** проекта:
- Обновляется название в системе
- **Автоматически обновляются ВСЕ записи табеля**
- Пользователь получает уведомление
- Всё в транзакции (rollback при ошибке)

Пример:
```
Пользователь добавил: "бкнс-150" (создал 10 записей)
Администратор переименовал: "БКНС-150"
Результат: Все 10 записей автоматически обновлены!
```

## 🐛 Если что-то не работает

```bash
# Проверить логи
tail -f /path/to/error.log | grep "ProjectModeration"
```

**Частые проблемы:**
1. Таблица не создана → выполнить SQL скрипт
2. Callback не обрабатывается → проверить, что proj_mod_ разрешён в CallbackqueryCommand
3. Счётчик не работает → проверить AdminHandler получает databaseService
