# 🔧 ДИАГНОСТИКА И ИСПРАВЛЕНИЕ ПРОБЛЕМЫ

## Проблема
После внедрения системы модерации проектов работают только кнопки главного меню, остальные callback queries не обрабатываются.

## Возможные причины

### 1. OPcache не обновился
PHP кэширует скомпилированные файлы, и изменения могут не применяться сразу.

### 2. Файлы не загрузились на сервер
Новые файлы могут отсутствовать на production сервере.

### 3. Синтаксическая ошибка
Хотя локальная проверка не показала ошибок, на сервере может быть другая версия PHP.

## 📞 Если ничего не помогло

Возможные проблемы и решения:

### Проблема: "Class ProjectModerationHandler not found"
**Решение**: Файл не загружен или путь неверный
- Проверить, что файл есть: `CustomCommands/Handlers/ProjectModerationHandler.php`
- Проверить права доступа: `chmod 644`

### Проблема: "Call to undefined method addPendingProject"
**Решение**: DatabaseService не обновлён
- Перезагрузить обновлённый DatabaseService.php
- Очистить OPcache

### Проблема: Кнопки не реагируют вообще
**Решение**: Webhook не работает
- Проверить webhook status
- Проверить логи Nginx/PHP-FPM
- Проверить, что hook.php доступен
