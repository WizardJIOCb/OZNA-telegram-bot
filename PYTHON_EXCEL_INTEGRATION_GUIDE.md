# Python Excel Integration Guide

## Overview

This guide explains how to use the Python script to convert bot-generated CSV reports into beautifully formatted Excel files with filters, styling, and auto-sizing.

## Prerequisites

### Required Python Packages
```bash
pip install pandas openpyxl
```

**Note:** These are the only packages needed. The script is lightweight and efficient.

## How It Works

### Workflow
```
Bot CSV Report → Python Script → Styled Excel File
```

### What the Script Does
1. ✅ Reads the CSV report generated by the bot
2. ✅ Sorts data by date and employee name
3. ✅ Creates styled Excel file with:
   - **Dark blue headers** with white bold text
   - **Auto-filters** on all columns
   - **Red highlighting** for idle time (Простой)
   - **Auto-adjusted column widths**
   - **Excel table format** with row stripes

## Script Breakdown

### 1. Reading CSV
```python
df = pd.read_csv(csv_path, sep=',', quotechar='"', encoding='utf-8-sig',
                 dtype=str, keep_default_na=False)
```
- Uses **comma separator** (matches our CSV format)
- **UTF-8 with BOM** encoding (ensures Russian characters display correctly)
- Treats all data as strings to prevent auto-conversion issues

### 2. Date Formatting & Sorting
```python
if 'Дата' in df.columns:
    df['Дата'] = pd.to_datetime(df['Дата'], format='%d.%m.%Y', errors='coerce') \
                  .dt.strftime('%d.%m.%Y')

if {'Дата', 'ФИО'}.issubset(df.columns):
    df['Дата_sort'] = pd.to_datetime(df['Дата'], format='%d.%m.%Y', errors='coerce')
    df = df.sort_values(['Дата_sort', 'ФИО']).drop(columns='Дата_sort')
```
- Converts dates for sorting
- Sorts by **Date** first, then **Employee Name**
- Maintains original date format (`dd.mm.yyyy`)

### 3. Excel Styling
```python
# Header styling
cell.font = Font(bold=True, color="FFFFFF")
cell.fill = PatternFill("solid", fgColor="1f4e79")  # Dark blue
cell.alignment = Alignment(horizontal="center", vertical="center")

# Highlight idle time
if isinstance(val, str) and 'Простой' in val:
    cell.font = Font(color="FF0000", bold=True)  # Red, bold
```

### 4. Auto-Width Columns
```python
for col in ws.columns:
    max_len = 0
    column = col[0].column_letter
    for cell in col:
        try:
            if len(str(cell.value)) > max_len:
                max_len = len(str(cell.value))
        except:
            pass
    ws.column_dimensions[column].width = min(max_len + 2, 50)
```
- Calculates optimal width based on content
- Adds 2 characters padding
- **Maximum width: 50 characters** (prevents overly wide columns)

### 5. Excel Table with Filters
```python
tab = Table(displayName="Tab", ref=f"A1:{chr(64+len(headers))}{len(df)+1}")
style = TableStyleInfo(name="TableStyleMedium9", showRowStripes=True)
tab.tableStyleInfo = style
ws.add_table(tab)
```
- Creates a formal Excel Table
- Enables **auto-filters** on header row
- Applies **row striping** for better readability

```python

df = pd.read_csv(csv_path, encoding='utf-8-sig')
```

### Issue 3: Dates Not Sorting Correctly
```python
# Check date format matches
df['Дата'] = pd.to_datetime(df['Дата'], format='%d.%m.%Y', errors='coerce')
```

### Issue 4: File Already Open Error
```
PermissionError: [Errno 13] Permission denied
```

**Solution:** Close Excel file before running script

### Issue 5: Empty Output File
**Check:** 
1. CSV file path is correct
2. CSV file has data
3. Column names match expected format

## Best Practices

### 1. File Naming Convention
Use consistent naming:
```
report_PROJECT_YYYY-MM-DD.xlsx
report_all_2025-10-25.xlsx
report_supervision_2025-10-25.xlsx
```

### 2. Archive Old Reports
Create monthly folders:
```
C:\Reports\
├── 2025-10\
│   ├── report_2025-10-25.xlsx
│   └── report_2025-10-31.xlsx
└── 2025-11\
    └── report_2025-11-15.xlsx
```

### 3. Backup CSV Files
Always keep original CSV:
- CSV = source of truth
- Excel = presentation format
- Never delete CSV after conversion

### 4. Version Control
If making changes to the script:
```
convert_to_excel_v1.py
convert_to_excel_v2.py  # With new features
```
