## Как проверить:

### Шаг 1: Откройте бота в Telegram
Найдите вашего бота @OznaWork_bot

### Шаг 2: Отправьте команду /start
Это обновит главное меню

### Шаг 3: Проверьте каждую кнопку

#### Кнопка "📊 Табель":
- Нажмите кнопку
- Должно появиться сообщение: "📊 Табель учета рабочего времени"
- С кнопками выбора подразделения

#### Кнопка "❓ Помощь":
- Нажмите кнопку  
- Должно появиться сообщение: "📘 Помощь"
- С кнопками разделов справки

#### Кнопка "👤 Профиль":
- Нажмите кнопку
- Должно появиться сообщение: "👤 Профиль пользователя"
- С кнопками действий профиля

#### Кнопка "⚙️ Админка":
- Нажмите кнопку
- Должно появиться сообщение: "⚙️ Панель администратора" (если есть доступ)
- Или запрос доступа (если нет прав)

## Если кнопки НЕ работают:

1. Убедитесь что webhook активен:
   ```bash
   curl https://api.ladyzenko.pro/tg/ozna/hook.php
   ```

2. Проверьте логи на сервере:
   ```bash
   tail -f /var/www/api.ladyzenko.pro/tg/ozna/telegram_bot_error.log
   ```

3. Если в логах ничего не появляется при нажатии кнопок - проблема с webhook
4. Если появляется "TextmenuCommand handling text" - команда работает
5. Если появляется ошибка - проверьте текст ошибки
