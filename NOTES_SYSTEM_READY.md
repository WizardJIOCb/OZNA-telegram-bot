## 🎯 СЦЕНАРИЙ ИСПОЛЬЗОВАНИЯ

### Создание заметки:

1. Пользователь → Отдел ПНР → Дата → Проект
2. Нажимает "📝 Заметки"
3. Выбирает "✍️ Оставить заметку"
4. Выбирает этап (например, "⚡ Электрооборудование")
5. Вводит текст заметки
6. ✅ Заметка сохранена!

### Просмотр заметок:

1. Нажимает "📝 Заметки"
2. Выбирает "📋 Посмотреть заметки"
3. Видит список этапов с количеством заметок
4. Выбирает этап
5. Видит список заметок (активные + закрытые)
6. Может открыть детали, редактировать, закрыть
