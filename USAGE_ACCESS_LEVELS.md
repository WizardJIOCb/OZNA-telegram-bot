# Использование системы уровней доступа

## Общее описание

Система уровней доступа позволяет управлять доступом пользователей к функциям бота. Всего существует 4 уровня доступа:

1. **Гость (0)** - Базовый уровень, только просмотр профиля
2. **Пользователь (1)** - Полный доступ к основным функциям бота
3. **Администратор (2)** - Доступ к админке и управление проектами
4. **Суперадминистратор (3)** - Полный доступ ко всем функциям

## Получение первых администраторов

### Шаг 1: Проверка текущих заявок на доступ

1. Зайдите в админку через меню "Админка"
2. Выберите "Заявки на доступ"
3. Просмотрите список заявок

### Шаг 2: Одобрение заявок

1. Найдите заявку от пользователя, которого хотите сделать администратором
2. Нажмите на заявку для просмотра деталей
3. Выберите "Одобрить"

После одобрения пользователь получит уровень доступа "Администратор" и сможет использовать админку.

### Шаг 3: Ручное добавление администраторов (если нет заявок)

1. Используйте скрипт `add_first_admins.php`:
   ```bash
   php add_first_admins.php
   ```

2. В скрипте укажите реальные ID пользователей:
   ```php
   $firstAdmins = [
       [123456789, "Иванов Иван", "987654321"],
       // Добавьте сюда реальных пользователей
   ];
   ```

## Сброс всех пользователей на уровень "Гость"

Для полного закрытия доступа всем текущим пользователям:

1. Используйте скрипт `reset_users_to_guest_level.php`:
   ```bash
   php reset_users_to_guest_level.php
   ```

2. Скрипт автоматически:
   - Сбросит всех пользователей (кроме суперадминов) до уровня "Гость"
   - Отправит уведомления пользователям о новой системе доступа

## Согласование доступа уровня "Пользователь"

После сброса пользователи могут:

1. Зайти в меню "Профиль"
2. Выбрать "Уровень доступа"
3. Нажать "Запросить повышение"
4. Администраторы получат уведомление и смогут одобрить запрос

## Управление уровнями доступа администраторами

### Администраторы могут:

- Просматривать заявки на повышение до уровня "Пользователь"
- Одобрять/отклонять заявки через админку
- Использовать команды `/promote` и `/demote`

### Суперадминистраторы могут:

- Все, что могут администраторы
- Назначать новых администраторов
- Управлять всеми уровнями доступа

## Часто задаваемые вопросы

### Почему пользователь не получил доступ после одобрения заявки?

1. Проверьте, что в функции `approveAccessRequest` вызывается `updateUserAccessLevel`
2. Убедитесь, что пользователь существует в таблице `ozna_data`
3. Проверьте логи на наличие ошибок

### Как добавить суперадмина?

Суперадмины теперь хранятся в базе данных. Для назначения суперадмина используйте один из следующих способов:

1. Через прямой SQL-запрос:
   ```sql
   UPDATE ozna_data 
   SET data = JSON_REPLACE(data, '$.is_super_admin', true) 
   WHERE user_id = [USER_ID];
   ```

2. Используя метод `setSuperAdmin` из `DatabaseService`:
   ```php
   $databaseService = new DatabaseService();
   $databaseService->setSuperAdmin($userId, true);
   ```

3. Используя метод `setSuperAdmin` из `AdminService`:
   ```php
   $adminService = new AdminService($messageService);
   $adminService->setSuperAdmin($userId, true);
   ```

### Как изменить уровень доступа пользователя вручную?

Используйте метод `updateUserAccessLevel`:
```php
$adminService->updateUserAccessLevel($userId, DatabaseService::ACCESS_LEVEL_USER);
```

## Безопасность

1. Все изменения уровней доступа логгируются
2. Пользователи не могут повышать уровень другим пользователям с равным или более высоким уровнем
3. Только суперадмины могут назначать администраторов
